## 验收行为

- 无重复原型直接创建。最终原型与已有词条重复时，新旧词条都需非空且同组不同的标注；普通词形命中不算。多原型命中同一词条只显示一行。
- 原绿色创建按钮打开原生 antd「词条标注」，两列「词条 / 标注」，显示词名、已有/新建、简短词性释义；旧标注可修改或保留，无示例、建议按钮、多余预览。
- 默认 trim、忽略大小写比较、最多 20 字，最终与后端契约统一。第三条的前两条可编辑，旧旧/旧新重复均拦截，取消恢复服务端原值。
- 「保存标注并创建」通过一次服务端事务更新旧标注并创建新词条，真实 onCreated 直接进入词形与发音，无再次创建或结果弹窗。
- 网络失败保留输入，冻结请求可重试；复用幂等和 surface token 重确认，并发 revision 变化不能静默覆盖。
- 列表和查询均在加粗词名下方显示次级标注，不新增列；最小编辑入口成功后刷新列表/详情。
- 删除 preview 参数、模拟列表、假 forms 流，接入真实接口。
