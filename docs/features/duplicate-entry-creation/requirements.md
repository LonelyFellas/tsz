# 同名词条独立创建修复

允许创建多个原形相同的独立词条，包括尚无有效词形的同名草稿。
检测结果展示已有词条、同名草稿与内置词典匹配；主词确认与创建区域继续保留。
已有草稿提供打开入口，提示可继续编辑或另建独立词条。
创建后的清空词形、单条/批量恢复和历史主词回填不得因同名草稿而失败。
保留有效原形匹配的确认、写权限和幂等规则；同名空草稿也必须通过数字标注区分，不要求另建说明。
删除区分说明的界面、请求字段、后端校验和新建审计字段，不保留兼容代码。
不改迁移或鉴权。

验收：连续和并发创建同名草稿须先确认标注，再返回不同 ID；同一幂等命令重放仍复用 ID；
前端显示主词确认与可用创建按钮，实际请求携带确认后的英美拼写。
