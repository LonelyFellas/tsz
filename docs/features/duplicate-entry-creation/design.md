# 实施与验证

依赖链：后端移除空草稿唯一校验 → 前端取消提示字段的创建阻断 → 本地真后端验收。
复用已有检测字段、匹配确认和同原型标注流程；取消唯一限制后，同名空草稿纳入标注分组。
标注创建、编辑和列表角标统一使用有效原形与尚无有效词形的初始主词，历史双 NULL 数据回退检测名称。
保存有效词形后不再使用旧初始名称占组；退出/重新进入初始组时均锁初始名称，防止并发读到过时分组。
空草稿的弹窗名称使用初始主词回退。
后端从 create、forms-clear、restore 中移除该校验，保留事务与 surface 锁。
回填工具保留坏快照、歧义原形 blocker，允许同名条目独立回填。
前端仍展示同名草稿，并保留两块卡片和创建操作；词典或词性配置不可用时禁止创建。
删除 `homograph_reason` DTO/wire 字段、文本说明状态和必填规则；新建审计不再写入该字段。
保留数字标注、事务、权限、版本与幂等校验；历史审计记录不修改。
同步 OpenAPI、wire 类型与生成快照，不保留旧字段兼容分支。

兼容：新前端配旧后端仍会收到 409；旧前端配新后端仍隐藏按钮。
移除说明字段后，新前端请求在旧后端同原型组中会被拒绝；旧前端携带已删除字段也会被新后端拒绝。
前后端需配套更新；本地更新后端 binary，已有 Vite 工作区同步生效。无数据库迁移。

验证：前端 UnifiedCreateEntryStep 回归、全量 Vitest、typecheck、修改文件 lint/format；
后端 lexicon_handler、lexicon_v3_lifecycle、fmt、clippy；OpenAPI 导出与契约快照同步。
实际创建验收使用独立自动化账号和测试词，不影响用户会话。

标注弹窗以一条规则说明数字标注，已有行展示词性、释义、创建人姓名和更新时间，删除重复新建提示。
`MatchedEntryContextV3.created_by_name` 为必填，使用管理员表姓名；同步严格 runtime schema。
