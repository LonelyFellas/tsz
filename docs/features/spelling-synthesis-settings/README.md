## 契约与保存语义

common/uk/us 变体新增可选、不可为 null 的 `spelling_speech: SpellingSpeechV3`：

```ts
interface SpellingSpeechV3 {
  content: RichTextV2V3; // text 必须等于规范化后的 spelling，仅允许 pause
  voice_profile: VoiceProfileV3;
}
```

`spelling_rich` 继续只存斜体、连读；编辑器将两份标注组合为同一正文，完成后分别保存，避免独立试听配置影响各条读法。普通改字同时迁移展示和停顿的码点位置；不改搜索、引用和合成来源中的纯文本拼写。

新增字段沿用现有 forms 保存、发布快照与历史读取，无数据库 migration。正文不一致、非法标注/停顿或无效音色会定位到变体的 `spelling_speech` 并拒绝保存。

省略字段且稳定 variant ID、方言和最终 spelling 未变时保留已有配置，包括旧客户端显式更新 `spelling_rich` 的情况。旧客户端改字且省略配置时不沿用失效偏移。显式空停顿数组与空 voices 是清除指令。

完整词条响应使用独立能力头 `X-TSZ-Spelling-Speech: v1`，13 个已有词条方法统一声明。缺省或未知值在响应副本省略 `spelling_speech`；不改变存储、幂等结果或原有 `X-TSZ-Spelling-Markup: v1`。Vary 包含两项拼写能力和句子格式能力。
