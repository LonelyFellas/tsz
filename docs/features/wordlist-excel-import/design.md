## 产品与实现规则

1. `.xls`（OLE/BIFF 工作簿）、`.xlsx`，文件最大 10 MB。仅一个工作表，固定三列表头「词汇 / 释义 / 注释」。合并单元格、多表、损坏/加密文件及伪装扩展名明确报错。
2. 最多 10000 个数据物理行，不含表头；完全空行跳过并保留其余行原始行号。词汇最多 200 字、释义最多 200 字、注释最多 1000 字。非文本及公式（含数组公式）须在预览中修正，不能静默丢弃。
3. 释义仅供用户核对，不覆盖或保存为平台释义；注释写入 `author_note`，对有权阅读词表的人可见。已有私密备注不受影响。
4. 文件通过按需运行的 Worker 本地解析，不上传原文件。固定使用 [SheetJS 官方发行版 0.20.3](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/)。XLSX ZIP 目录先限制文件项数量及展开声明总量（1000 项、50 MiB），解析限制读取行数，Worker 超过 15 秒终止且可取消。
5. 每次请求最多 100 个词汇，只自动绑定归一化后唯一精确命中的平台词条。多匹配、近似匹配须用户选择；未匹配行可修改、查找候选或明确删除。
6. 预览每页 50 行，可仅看待处理行。匹配请求串行分批，可取消；失败保留已完成批次，重试只处理未完成行。改词撤销原匹配，旧请求不能覆盖新预览。
7. 按最终 `entry_id` 检查文件内重复及与编辑器已有项重复，并显示位置；不自动合并注释。原内容冻结保留，确认追加才更新编辑状态，取消不改变原内容。仅新建时唯一且完全空白的占位行被替换。
8. 追加后沿用现有保存接口、顺序、注释、幂等和版本保护，不立即持久化。保存请求体沿用现有上限，413 时明确提示减少词条/缩短注释，并保留可修改的内容；不扩大通用请求体限制。

## 接口与兼容

新增 `POST /api/v1/wordlists/import-matches`：`{ words: string[] }` → 按原顺序返回 `{ items: [{ status: matched|ambiguous|unmatched, candidates: [...] }] }`；每行最多三个候选。以当前有效发布的词形索引查询，同一条目的方言/多词形去重，归档、旧发布不参与。查询完成后锁定候选并复核发布，等待期间候选变化时整行不自动绑定，避免歧义错误缩成唯一命中。

复用现有用户鉴权、手机号门禁、账户有效性复核。不写词表数据，不新增迁移或编译期 SQL 宏，故不修改 `.sqlx`。OpenAPI 由选定后端原生导出，前端显式 `OPENAPI_SOURCE` 同步响应 runtime schema；wire 保持 snake_case。

候选前后端完整链路见下文。新接口为增量路径，旧接口响应不变；未另跑旧版本服务组合。未来应先更新后端再开放新版 Web。新 Web 连接旧 API 时匹配失败保留预览，不能假装成功；回退 Web 不影响已按现有模型保存的词表。现网版本和发布未在本次核实或执行。
