# Admin 多端登录需求评估

状态：2026-10-07 已按用户确认方案实施；验证结果见 [acceptance.md](acceptance.md)。

## 目标与范围

同一管理员可以在电脑和 iPad 浏览器独立登录、持续操作，新登录不挤掉其他设备。
普通管理员与超级管理员采用同一会话策略；保留现有权限、密码加短信验证码登录和 Admin/C 端凭证隔离。
本期不设设备数量上限，不新增设备识别、在线设备列表、异地通知或逐设备远程退出。
“设备”在本需求中指独立浏览器 Cookie 环境，同一浏览器的标签页共用会话，不按物理设备计数。

## 用户行为

| 操作                               | 期望                                                                   |
| ---------------------------------- | ---------------------------------------------------------------------- |
| 电脑登录后，iPad 登录同一账号      | 两端均可请求接口、轮换令牌及刷新页面恢复登录                           |
| 电脑退出登录                       | 清除当前浏览器登录，iPad 继续使用                                      |
| 选择退出所有设备                   | 包括当前端的全部已有登录失效；其他端在下次请求或刷新时进入重新登录流程 |
| 修改自己的密码、超级管理员重置密码 | 全部旧访问令牌和刷新令牌失效，必须重新认证                             |
| 禁用管理员，再重新启用             | 禁用时撤销全部旧登录，重新启用后旧凭证仍不能恢复使用                   |
| 正常刷新登录态                     | 各会话独立轮换，并继承各自最初的刷新令牌过期时间                       |
| 某会话到期                         | 仅该会话需要重新登录，不改变其他会话的到期时间                         |

继续采用现有 Admin 刷新令牌绝对有效期，配置默认 7 天；访问令牌默认 15 分钟，实际值以部署配置为准。
这里的 7 天是刷新能力的上限，不新增“到期瞬间撤销尚有效访问令牌”的承诺。
普通退出沿用“吊销当前刷新令牌并清除本地态”；本期不新增按会话撤销访问令牌的模型。
“全部失效”指安全变更事务提交后，新发起的鉴权不能继续使用旧凭证；不撤回已完成鉴权的在途操作，也不新增实时推送踢下线。

## 已有能力与必要缺口

- 已有：多会话存储结构、令牌原子轮换、独立 Cookie、账号安全版本、改密全端失效、当前退出/全部退出接口与菜单。
- 必改：登录签发不再吊销其他会话，但保留行锁、安全版本和账号状态检查。
- 必改：全部退出同时撤销旧访问令牌与刷新令牌；当前实现仅吊销刷新令牌。
- 必改：禁用账号同时撤销旧登录；当前仅更新状态，重新启用可能恢复旧凭证。
- 必改：全部退出的服务端失败不能被前端静默当作全部成功；明确失败并允许重试，普通本机退出仍可使用。
- 回归：刷新令牌重放检测继续保留；宽限窗口内不连带吊销，窗口外可使该账号全部刷新会话失效。

## 验收标准

1. 两个独立浏览器环境登录同一账号后，双方均能多次刷新令牌和访问后台；第三个环境登录不挤掉前两者。
2. 退出其中一个环境后，该环境的已退出刷新令牌不能使用，其他环境继续正常工作。
3. 全部退出成功后，所有已有访问令牌访问受保护接口被拒，所有已有刷新令牌均不能续期；其他管理员和 C 端不受影响。
4. 全部退出请求失败或结果未知时，界面明确提示未确认完成，不显示全部退出成功；成功时清本地态并整页跳登录页。
5. 自助改密、重置密码、禁用后重新启用，均不能用旧访问令牌或旧刷新令牌恢复登录。
6. 登录/刷新与上述安全变更并发时，不得留下可绕过变更的旧凭证；事务失败不允许只完成一半撤销。
7. 各设备刷新不延长原有刷新期限；过期、重放、跨 Admin/C 端凭证拒绝等已有边界继续成立。
8. 使用同一浏览器多标签页验证基本恢复与退出行为；若发现共享 Cookie 刷新竞态，单独记录，不能误报为跨设备互踢或宣称已解决。

## 交付边界

本次完成前后端实现与验证，后续已获本地提交授权；不包含推送、合并或部署，不需要数据库 schema 迁移。
本需求替代后端历史设计中的 Q1 严格单登录决策；保留各会话绝对刷新期限。
