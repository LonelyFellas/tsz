# 词表工作区按编辑器方式展示内容

## 目标与范围

- 左侧目录树负责导航、选择词表和文件夹管理，保留拖放范围高亮。
- 右侧仅显示当前词表的词条内容或编辑界面，移除词表列表及重复的文件夹列表、搜索、分页与批量选择。
- 未打开词表时显示“从左侧选择词表”的提示，创建空间保留创建词表入口。
- 已打开词表或正在新建时，点击文件夹／根节点只操作左侧目录，不导航离开内容、不触发离开编辑器确认，未保存草稿保持不变。
- 切换创建／收藏空间、回收站或关闭词表后回到选择提示；选择左侧词表后打开其内容。
- 文件夹新建、重命名、移动、递归删除、词表恢复与清空回收站均从左侧操作；回收站为空时禁止清空。

## 接口与验收

复用现有目录、词表详情与编辑接口，无需新增后端能力。

组件回归覆盖选择提示、阅读／编辑／新建内容在目录操作中保持不变、草稿保留、目录管理、拖放、失败恢复和账户隔离。真实页面使用生产构建，通过本地代理连接测试环境验收。

验证命令：`pnpm --filter @tsz/web test src/features/wordlist/components/WordlistLibrary.test.tsx`、`pnpm --filter @tsz/web build`；提交及推送仍执行原生 hooks。
