# 被引用节点保护：禁用破坏性操作并显示引用

2026-09-15。起因：测试服 `for` 词条（01a09b00…）保存词形连续 409。词形被多维例句标注，管理员把
「英美音标是否有区别」切成「是」，英美通用变体被拆成英/美两个新变体，保存被后端拒绝，前端只显示「操作未完成」。
本地（后端 c80d829）已稳定复现：切「是」保存必 409；切回「否」保存 200；只改音标 200。

用户决定：这种情况直接禁用，旁边显示引用并能跳转到具体位置；范围不只英美，词性、词形、词义等凡可能被引用的节点都要保护。

## 目标

- 管理员在向导里提交前就知道哪些词性 / 词形 / 英美变体 / 词义被别处引用；会破坏引用的操作直接不可点，而不是保存才 409。
- 被禁用处能看到「谁在引用」，一键跳到引用所在的具体位置去解除或调整。
- 保存仍因引用失败时（并发新增引用等），界面说清原因与引用位置，不再只有「操作未完成」。

目标端：`apps/admin` V3 向导第 2 步「词形与发音」、第 3 步「词义与例句」；后端 tsz-rust 补只读接口与校验对齐。

## 引用类型（tsz-rust origin/main c80d829 实查）

| #   | 引用                                                            | 指向本词条的节点                 | 现在会拦哪些写                                                                                   |
| --- | --------------------------------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------ |
| 1   | 多维例句标注（共享例句 linked）                                 | 词性、原形、词形、英美变体、词义 | 词形保存、词义保存、发布、切换版本 409 `reference_conflict`；移入垃圾桶 409                      |
| 2   | 已发布内容的词义引用（来源词条发布时写入）                      | 词义                             | 词形保存（删词性连带删词义）409 `form_reference_conflict`；发布 / 切换版本 422；**词义保存不拦** |
| 3   | 草稿关联词（其他词条的近义 / 反义 / 派生）                      | 词义                             | 词义保存 422 `relation_target_unavailable`；**词形保存删词性不拦**                               |
| 4   | 短语成分用词（短语引用单词）                                    | 词性、原形、词形、英美变体、词义 | **保存都不拦**，只在删除词条时拦                                                                 |
| 5   | 草稿里的文本关联、旧 `sentence_links` / `sentence_associations` | 词义等                           | 分散或历史机制，见「范围」                                                                       |

发音、释义（定义）、语法结构、语义区间没有任何入站引用，不受本需求限制。

## 需要禁用的操作

| 节点     | 操作                                                     | 禁用条件                         |
| -------- | -------------------------------------------------------- | -------------------------------- |
| 词性     | 删除词性（第 2 步、第 3 步页签）                         | 该词性下任一节点被引用           |
| 词形     | 删除词形（即「从本组移除」）、删除变化组连带删除孤立词形 | 词形被引用，或它是某条引用的原形 |
| 词形     | 修改词形类型                                             | 同上                             |
| 英美变体 | 切换「英美拼写是否有区别」「英美音标是否有区别」         | 该变化组内任一词形的变体被引用   |
| 英美变体 | 修改拼写                                                 | 见未决问题 Q2                    |
| 词义     | 删除词义；移到其他词性（若提供该操作）                   | 词义被引用                       |

## 显示与跳转

- 被引用节点旁显示「被引用 N」；禁用按钮悬停说明「被 N 处引用，需先解除引用」。
- 点开列出每条引用：类型（多维例句 / 近义词 / 反义词 / 派生词 / 短语成分 / 已发布内容），来源摘要（例句原文并高亮被标注片段；或来源词条词头 + 词义释义 + 草稿 / 已发布），指向本词条的节点。
- 每条可跳转：
  - 多维例句：进入本词条「词义与例句」对应词义卡片的多维例句区块，并直接打开这条例句（本页内跳转，词形页未保存输入保留）；另给「在多维例句库打开」。
  - 关联词、已发布内容引用、短语成分：新标签页打开来源词条向导对应步骤并定位到来源节点，不丢当前编辑。
- 只读场景（别人的草稿）照常显示引用列表与跳转，不提供修改入口。

## 异常

- **失效引用**：引用指向的节点在草稿里已不存在或拼写已对不上。草稿保存只拦本次改动破坏的引用，已失效的旧引用只挡发布与切换版本（见 Q6）。页面顶部提示「有 N 条引用已失效，需先处理」，列出并可跳转；操作锁只算未失效的引用，不挡本地修复。
- **引用数据加载失败**：不阻塞编辑，退化为保存时由后端兜底，并提示「引用信息暂不可用」。
- **本地新增、尚未保存的节点**：没有引用，不受限。
- **他人同时新建引用**：保存仍被后端拦截；错误提示展示原因与引用列表，并刷新引用数据。

## 范围

- 本期：引用类型 1–4；上表操作；失效引用提示；保存失败的错误展示与引用列表。
- 不做：切换英美时自动把引用迁到新变体；新的解除引用流程（沿用各来源现有入口）；词条列表 / 垃圾桶的引用展示（已有 `reference_summary`）；类型 5（草稿文本关联在来源发布后即成为类型 2，另两类为历史机制）。

## 验收标准

1. 原形变体被多维例句标注：英美两个切换控件、删除该词形、修改词形类型、删除该词性均不可点，悬停有原因；节点旁显示「被引用 1」。
2. 点开列表可见例句原文且被标注片段高亮；跳转后进入词义与例句对应词义并打开该例句；回到词形页，未保存修改仍在。
3. 解除该标注后回到词形页，控件恢复可用；切换英美并保存成功。
4. 词义被其他词条的近义词引用：删除该词义、删除其词性不可点；跳转在新标签页打开来源词条对应词义。
5. 单词的词形被短语成分引用：同第 1 条；跳转到短语词条对应成分位置。
6. 词义被已发布内容引用：删除该词义、删除其词性不可点。
7. 构造失效引用：顶部提示出现并可跳转；处理前草稿照常可以保存、发布被拦；处理后提示消失，发布恢复正常。
8. 绕过界面仍触发引用类 409 / 422 时，界面显示后端原因与引用列表，不再只显示「操作未完成」。
9. 没有任何入站引用的词条，行为与现在完全一致。

## 决定记录

2026-09-15 用户确认：Q1–Q5 全部按下列建议执行，进入实施。

- **Q1 引用类型范围**：建议 1–4 本期都做。类型 4（短语成分）后端保存目前不拦，是否同时补后端保存校验？建议补，否则前端禁用了、后端却放行，口径不一。
- **Q2 拼写**：直接禁用拼写输入框会挡住纠错。建议输入框保持可编辑，但与被引用片段规范化后对不上时即时标红、禁止保存并列出引用；规范化后仍一致（如大小写）照常保存。
- **Q3 例句跳转落点**：建议本词条词义卡片内就地打开，例句库作备用链接。
- **Q4 后端改动**：方案需要 tsz-rust 新增只读接口并统一写校验（见 design.md），需同意动后端。
- **Q5 校验补齐**：词义保存不拦类型 2、词形保存删词性不拦类型 3。是否顺带补齐，使界面禁用与后端拦截完全一致？建议补；上线前先查测试服存量里会因此开始报错的草稿数。
- **Q6 失效引用是否挡草稿保存**（2026-09-15 推送前审查后确认）：草稿保存与词形影响预览只拦本次改动破坏的引用（已保存内容里成立、提交内容里不成立）；已失效的旧引用读接口照常标出，只挡发布与切换版本。原因：关联词可以指向只在发布版里还有的词义，来源词条归档期间目标删掉节点、之后来源恢复，都会造出目标编辑者自己解不开的失效引用，按现状拦会让词条永远保存不了。操作锁（删词形、改类型、英美切换、删词性、删词义）同样只算未失效的引用。
