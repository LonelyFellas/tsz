# 实现方案

依赖：现有 relations 数组和后端多目标义项引用可复用；前端分组、多选和回显需要修改。
关键路径：按目标词条分组 → 编辑/预览 → 保存重开 → 后端发布回归。

仅将同一源 sense 内的 derivative、相同 target_word_id 合为展示组；未绑定文本和其他关系保持逐行。
wire 不变：每个被选义项对应独立 relation，保留已有 UUID，新选项生成 UUID。
一行修改分数或删除应用于整组；改选词条清理旧组；取消全部义项保留一条待选择行。
编辑器按 relation id 回填各义项快照；打开已保存词义选择时复用关联搜索获取可用候选。
预览合并展示多个词义。后端现有存储及引用按 relation id 和目标 sense id 保留，不需要迁移。

发布兼容：本项不改变契约，后端无需升级；本会话此前纯文本发布修复仍须后端先发布。
回退旧前端会将多个义项显示成多行，不丢数据。
验证：前端编辑/分组/预览测试和类型检查；后端双义项保存发布再取消一项的集成测试。
