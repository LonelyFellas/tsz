# 专用词形组：词义绑定与关联筛选

2026-09-17 规则修订：多组绑定、Popover 选择及词形组入站引用。旧版验收记录仅证明原单组实现，不代表本次修订已完成。

## 产品规则

- 通用组默认适用当前基本词性下的全部词义，不显示“通用”标签。
- 专用组只适用绑定的一个或多个词义；组与词义必须属于同一个基本词性。
- 一个词形只属于一个变化组；相同拼写的不同词形 ID 不合并。
- 一个专用组可以绑定多个词义；同一个词义也可以同时绑定同基本词性下的多个专用组，组之间不互斥。

## 编辑交互

1. 卡片头部右侧未绑定时显示“设置专用词义”，已绑定时显示蓝色实心按钮“专用词义 · N”，未绑定使用描边样式，位于展开/收起按钮之前；点击打开 Popover；选择列表、确认、取消和恢复全部词义操作均位于浮层内，不改变卡片展开状态。
2. 移除左侧“专用”标签及单独的数量摘要，展开和折叠时均由右侧入口显示绑定状态与数量；词义内容与编辑控件统一放在 Popover 中，卡片正文不再显示“适用词义”摘要。
3. 编辑区仅列当前基本词性的词义，至少选择一项才能确认。其他专用组已绑定的词义仍可选；新增绑定保留已有组的绑定。
4. 没有词义时引导添加；新建未保存的词义先保存再绑定。已保存但释义暂空的词义仍可见，已有绑定不因摘要为空而丢失。
5. 确认更新草稿，取消或点击浮层外关闭时放弃本次未确认选择。恢复原绑定后不产生假未保存提示。
6. “恢复适用全部词义”只解除当前组的专用限制和绑定，不影响其他组；页面保存仍执行影响确认与引用保护。
7. “保存草稿”在一个事务内保存组状态与既有词义绑定，不先产生一个尚无绑定的专用组。

## 关联行为

- 关联单词：词条 → 词形 → 该词形允许的词义。
- 关联短语：短语词条 → 成分用词 → 词形 → 该词形允许的词义。
- 短语成分用词复用同一选择器；专用组无适用词义时不可选，不能回退到全部词义。
- 切换词形时不丢失另一组的合法词义；分页、方言与稳定目标 ID 行为不变。
- 保存、发布均检查词形与词义是否匹配。固定发布版本使用对应快照，不被目标的新草稿改变。
- 第 3 步不能直接解除一个专用组最后的词义绑定，应通过词形组恢复全部词义。

## 词义引用与删除保护

- 每个词形组对词义的绑定计为一条入站引用，在词义侧与多维例句等引用累计展示，并能查看具体来源组。
- 绑定两个组计两条；同组内多个词形不重复计数；解除一组只减少该组的一条引用。
- 删除词义前检查词形组、短语成分、多维例句及其他既有引用；仍被引用时禁止删除，先解除引用。
- 后端依据保存前的引用关系拦截删除，不能通过提交时删除词义及其绑定字段绕过。

## 范围与验收

复用已有 scope、一形一组和原子保存机制；新增多组绑定关系及同词性约束，保留历史单组数据语义，不清库，不自动删除或改写历史错误关联。
不涉及 C 端展示、无需具体词形的同反义词关系编辑。

验收覆盖同词性隔离、通用全义/专用多义、同拼写不同组、空范围、取消/折叠/恢复、失败保留输入、确认 token 不可换补丁复用、入站引用保护及历史发布快照。
自动验证及真实浏览器证据见 [browser-acceptance.md](browser-acceptance.md)，契约与发布顺序见 [design.md](design.md)。
