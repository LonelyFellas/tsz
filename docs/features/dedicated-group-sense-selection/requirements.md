# 专用词形组：词义绑定与关联筛选

评审基线：前端 `617f7db`，后端 `02de3eb`。实现与本地验收已完成，本次提交 PR 审核，不包含合并或部署。

## 产品规则

- 通用组默认适用当前基本词性下的全部词义，不显示“通用”标签。
- 专用组只适用绑定的一个或多个词义；组与词义必须属于同一个基本词性。
- 一个词形只属于一个变化组；相同拼写的不同词形 ID 不合并。
- 一个专用组可以绑定多个词义；每个词义沿用现有单值绑定，不扩展为绑定多个专用组。

## 编辑交互

1. 卡片头部右侧提供“专用词义”，位于展开/收起按钮之前；折叠时点击会展开并进入卡片内编辑。
2. 专用组保留标题标签，展开时直接显示词义摘要，折叠时显示数量摘要；不再使用弹窗或正文重复入口。
3. 编辑区仅列当前基本词性的词义，至少选择一项才能确认。其他专用组占用项禁选，不静默转移绑定。
4. 没有词义时引导添加；新建未保存的词义先保存再绑定。已保存但释义暂空的词义仍可见，已有绑定不因摘要为空而丢失。
5. 确认更新草稿，取消保持原状态；收起再展开保留未确认勾选。恢复原绑定后不产生假未保存提示。
6. “恢复适用全部词义”解除专用限制；页面保存仍执行影响确认与引用保护。
7. “保存草稿”在一个事务内保存组状态与既有词义绑定，不先产生一个尚无绑定的专用组。

## 关联行为

- 关联单词：词条 → 词形 → 该词形允许的词义。
- 关联短语：短语词条 → 成分用词 → 词形 → 该词形允许的词义。
- 短语成分用词复用同一选择器；专用组无适用词义时不可选，不能回退到全部词义。
- 切换词形时不丢失另一组的合法词义；分页、方言与稳定目标 ID 行为不变。
- 保存、发布均检查词形与词义是否匹配。固定发布版本使用对应快照，不被目标的新草稿改变。
- 第 3 步不能直接解除一个专用组最后的词义绑定，应通过词形组恢复全部词义。

## 范围与验收

复用已有 scope/form_group_id、同词性外键和一形一组约束；无数据库迁移，不清库，不自动删除或改写历史错误关联。
不涉及 C 端展示、词义多组绑定、无需具体词形的同反义词关系编辑。

验收覆盖同词性隔离、通用全义/专用多义、同拼写不同组、空范围、取消/折叠/恢复、失败保留输入、确认 token 不可换补丁复用、入站引用保护及历史发布快照。
自动验证及真实浏览器证据见 [browser-acceptance.md](browser-acceptance.md)，契约与发布顺序见 [design.md](design.md)。
