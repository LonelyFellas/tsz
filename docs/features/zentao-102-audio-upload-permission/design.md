# 禅道 #102：独立上传音频权限

来源：<http://47.121.142.19/zentao/index.php?m=task&f=view&taskID=102>，以 2026-10-11 激活备注为准，复用已完成的词库权限功能。

## 范围与依赖

- 新增 `speech.upload_audio`，位于智能词库板块。名称「选择发音 – 上传音频」；说明「能够在智能词库选择发音时，直接上传音频给文本配音。」
- 复用既有上传凭证、直传、confirm、资产读取链路；不新增音频业务。
- 上传要求新权限 AND 原有四项内容写权限任一：`words.create`、`words.edit`、`sentences.create`、`sentences.edit`。既有权限依赖仍由授权内核核验。
- 新权限没有 AND 型静态依赖：原有前提是 OR，不能强行加 `words.access` 而扩大仅例句创建者的读取范围。单独授予上传权限不会赋予内容编辑或跨资源读取能力。
- 词库与例句共用上传服务，统一执行新门禁；已有音频的试听和按原有编辑权限移除引用不要求上传权限。
- 上传中撤权：前端中止在途请求、禁止重试并忽略迟到回调；后端签名前后、confirm 和对象复制/交付沿原有重新鉴权路径检查新权限。

## 迁移与兼容

按本会话保留原能力的口径，以一次性 up 迁移为原本有有效内容写权限的管理员补 `speech.upload_audio`，保留授权来源并递增权限版本。孤立的无效写权限不补授权，也不增加其他模块访问权。已有内容写权限标签同时补上传权限，维持原标签能力。
旧版授权迁移预览同步包含上传能力。down 在存在可写内容但未授予上传权限的账号或标签时拒绝回滚，避免旧代码恢复隐含上传能力。
迁移版本 `20261011030000` 与 #88 的 `20261011020000` 不冲突；两任务都合入时，测试中的当前迁移版本取两者最大值。

配套发布先后端及迁移，再前端。旧前端在被撤销独立上传权限后会收到后端 403；新前端连接旧后端的普通管理员会禁用上传，因此不适合前端先发布。新权限收紧后禁止直接回退到旧后端。请求/响应形状不变，仅更新 OpenAPI 403 说明与来源哈希。

## 验收与交付边界

- 内容编辑或语音合成不隐含上传权限；有新权限但无内容写权限也不能上传。
- 无权选文件、重试时不发上传请求；已有音频仍可试听。
- 上传中撤权中止前端请求，后端拒绝新凭证、confirm 首次/重放及迟到交付。
- 在隔离数据库验证授权迁移与回滚守卫；本地合成音频验证 UI → API → 存储 → confirm → 再次读取。
- 本次仅本地实施与验证，未提交、push、PR、合并、部署或修改禅道任务状态。#121/#88 各自工作树保持不变。
