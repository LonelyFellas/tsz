## 前端

VoiceEditor 默认语法模式不变，关联模式将原「语法结构」工具替换为「关联单词」「关联短语」。词库请求与级联面板由 admin 注入，voice-editor 只处理文字、标注、选段和历史状态，向选择器传入当前 kind。

V3VoiceTextField 默认显示可换行的普通输入框及右侧编辑图标/「编辑器」入口；点击后才挂载现有 VoiceEditor，完成后收起。两种视图实时回写同一份 RichText、text_links 与语音配置，普通输入沿用 editRichText / remapTextLinks，避免丢失隐藏标注或错误保留关联。data-v3 定位属性始终保留在当前实际输入框上。完成按钮在宿主容器内右下角绝对定位，同时给标注层与透明输入层留出相同底部空间；隐藏空 badge 行，消除顶部多出的 8px 间距。此次入口切换不改变后端契约。

V3 宿主向共享编辑器传入 textReadOnly：隐藏文本工具、锁定正文输入及其变更回调，同时保留标注和语音工具的可编辑状态。加载期间的输入也只读，避免绕过“文字在外部编辑”的规则。共享编辑器未启用该属性时沿用原行为，以兼容仍直接使用它的旧入口；整体 readOnly 与仅正文只读相互独立。工具栏首个工具不渲染前置分隔线。

两个关联工具复用 MarkupPanel 的 Popover，位于按钮上方，选词提示和「选择关联短语」操作放在弹层内，普通点击正文时保持展开。选择新候选或查看原关联时收起工具提示层，使用正文锚点上的关联弹层。

「关联单词」点击一个未关联源词后立即按「单词 → 词形 → 词义」单选。「关联短语」先通过普通点击选择至少两个未关联源词，再点击「选择关联短语」打开同一面板四级级联：「短语 → 成分用词 → 词形 → 词义」。不提供「短语本身」；无可用成分的短语标记不可选。成分按短语发布、词义和成分 ID 合并重复命中，不在级联下方另列入口；不同词义的同名成分保留并用所属释义区分。展开成分时按需查询目标词形词义。候选方言偏好过滤、查询失败与空状态继续使用原成分选择逻辑。

使用 Unicode 码点区间，排除词首尾标点，保留词内撇号与连字符。短语模式普通点击追加或取消源词，允许非连续选词；连续词合段，未选择的中间词保持独立，不跨段落。单词模式每次只保留一个源词。切换模式、编辑文本、撤销重做时重置临时选择。

每个位置只保留一条人工关联。点击与原关联重叠的词，按关联 ID 进入查看状态，不加入当前选词；查看完整来源区间和目标摘要，只能清除，且不查询候选。清除按关联 ID 移除整组，其他关联不变；之后才允许重新选择。VoiceEditor 在选择与提交两处阻止重复关联，不再过滤并替换重叠关联。查看已有目标的 adapter 不渲染可变更的级联，避免用切换按钮绕过规则。原成分用词的替换规则不受此次正文交互调整影响。

候选请求复用已存在的 kind 过滤参数：单词模式传 word，短语模式传 phrase，并对返回结果再次按类型过滤。短语选词阶段不挂载选择器，因此没有候选请求。原成分用词入口不传 targetKind，保留原有规则。此次按钮拆分无需修改后端或数据契约。

文本在已关联区间外改变时平移；触及原词、拼接成新词时清除失效关联并提示。文字、富文本标注、关联一起进入撤销与重做快照。按需加载或功能关闭时的文本框使用相同标注迁移及关联迁移，避免保留错误位置。

V3LinkedEnglishTextField 对 common 或已就绪的 uk/us 变体逐一装配，更新只修改当前变体。中文释义与汉语译文保留原控件。英文切为中文且存在关联或发音配置时，先确认移除这些设置，取消保持原值。cloneVariant 保留 voice_profile、audio_assets 与 text_links，保存前去除服务端只读快照。预览复用 RichTextReadOnly，附上「原词段 → 目标词 · 词义」。

## 数据契约

`RichTextVariantV3.text_links` 是可选数组，直属正文变体，源身份由变体 id 确定。每条关联字段如下：

| 字段                                                 | 含义                                                                 |
| ---------------------------------------------------- | -------------------------------------------------------------------- |
| id                                                   | 关联稳定身份                                                         |
| source_segments                                      | 有序、非重叠的 start/end/surface，码点范围                           |
| target_word_id / target_publication_id               | 目标词条及发布版本                                                   |
| target_pos_id / target_base_form_id                  | 词性及原形归属                                                       |
| target_form_id / target_variant_id / target_sense_id | 最终选择的词形、方言变体及词义                                       |
| via_phrase（可选）                                   | word_id / publication_id / sense_id / component_id，验证短语成分来源 |
| target_headword / target_gloss（只读）               | 服务端从目标发布快照生成；客户端提交会被拒绝                         |

每段正文最多 100 条关联，每条最多 20 段。区间必须切回原文、覆盖整词、不重叠、不跨段落；全词条关联 id 不重复。不得自引用，目标路径须完整属于所选发布快照，短语成分须属于指定短语词义且指向所选词条。同一正文对同一目标词义使用一个发布版本。

继续使用现有 meanings 保存端点与 revision 校验；候选检索继续使用 `POST /admin/lexicon/entries/component-targets/search`。新增 `capabilities.text_links`，不新建搜索或点选保存端点。

## 后端持久化、发布与兼容

保存先按变体身份处理字段 presence，再验证范围和目标。V3 到 V2 的既有转换不会承载新增字段，转换后按原变体 id 恢复 text_links；发布快照使用同一路径。

例句旧 `associations` 仍是只读输出。人工关联在自动解析完成后叠加，只移除实际选段重叠的自动结果，清除后恢复自动规则。人工关联不会作为可写的旧 associations 回传。

发布将引用写入 `entry_publication_sense_refs`，新增 `text_link` 类型，source_node_id 使用正文变体 id；目标发布、目标词义与经由短语均受校验和引用保护。使用目标发布行读取及目标词条共享锁，沿用既有删除/恢复及发布切换约束。历史发布快照自带 text_links，缺字段的旧快照按无人工选择处理。切换生效版本沿用现有语义：只切换发布指针，保留正在编辑的草稿；历史预览读取对应不可变快照。

兼容规则：

- 缺 text_links 且正文不变：保留已有数据。
- 缺 text_links 且修改了已有人工关联的正文：拒绝并定位正文。
- 显式 []：清除人工关联。
- capability 缺失：前端不发送新增空字段，不允许静默丢弃已有非空关联。
- 先发布能接受新增可选字段的前端 runtime 契约，再发布后端迁移与接口；两端完成前不进行关联写入验收。回退前端时不能编辑未知关联正文；回退数据库约束前必须处理已有 text_link 引用，迁移不会删除引用数据。

权威契约由 tsz-rust `docs/openapi.json` 导出，前端快照、运行时 schema 与 snake_case 类型同步。验证设计见 test-matrix.md，实际证据见 verification.md。
