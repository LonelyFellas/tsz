# 释义语句与英文例句编辑器：需求

状态：2026-09-07 用户确认推荐方案，进入前后端 dev 实施。中文保留文字编辑；短语支持成分选择层；上传沿用现有开关，暂不补上传后端。

## 用户已确认的目标

1. 管理后台的两处正文增加编辑器：多维释义的「释义语句」、多维例句的「英文例句」。
2. 编辑器基本能力与现有「语法结构」编辑器一致，工具栏中的「语法结构」按钮替换为「关联单词」「关联短语」两个按钮。
3. 关联交互与现有「成分用词」的关联功能极其类似，优先复用其级联选择方式。
4. 用户提供的图片作为关联单词、短语及语音设置的功能参考，界面沿用现有 admin / antd 样式。
5. 前后端后续直接在各自主工作目录的 `dev` 分支开发。

## 场景与范围

管理员在词条的词义步骤中通过普通输入框录入正文，点击右侧带小编辑图标的「编辑器」展开工具，设置连读、停顿、发音及关联；完成后收起回到输入框，保存后能重新查看和修改。

## 交互规则

### 编辑器

- 语法结构、英文释义及英文例句默认显示普通输入框，右侧为小编辑图标加「编辑器」按钮；支持长句换行和已有多行正文。
- 编辑器在原位置展开，「完成」悬浮在内部右下角，不在上方另占一行。展开后上边缘与相邻等级、释义方式输入框对齐。
- 编辑器内不提供「文本」按钮，正文只读；改字统一在外部普通输入框进行。内部仍可编辑标注、关联与发音设置，按 Esc 或关闭工具也不会恢复改字。
- 两个新增英文入口使用同一套内联编辑器，工具顺序沿用现有布局，「语法结构」原位置显示「关联单词」「关联短语」。
- 点击关联按钮打开上方 Popover，选词提示及「选择关联短语」按钮都放在其中；点击正文选词时保持展开，不在编辑器下方常驻操作区。
- 连读、停顿、音色、语速、音频及标注撤销/重做按实际支持能力复用；文字编辑由外部输入框承担。
- 「关联单词」下点击一个词，立即打开仅含单词候选的级联面板；始终只选择一个源词，按住 Ctrl / ⌘ 也不追加。
- 「关联短语」下先依次点击至少两个源词，无需组合键；支持不连续选词，再次点击取消选择。同一组不能跨段落，未选中的中间词不算入关联。
- 选词期间不查询候选；选择完成后点击「选择关联短语」，打开仅含短语候选的级联面板。少于两个源词时此按钮不可用。
- 切换两种关联模式时清空临时选词并关闭候选面板；已经保存的关联保持不变。
- 已关联的单词不能再加入任何新关联，包括单词和短语关联。点击已关联词只查看原关联及清除入口，不展示可重复关联的候选；点击短语组内任意词即可查看整组。
- 必须先清除原关联，再重新选择。清除短语关联解除整组，不影响其他关联或相同拼写的其他位置；切换工具不会丢失已有关联。

### 关联目标

- 单词选择沿用「词条 → 词形 → 词义」三级级联，选择叶子立即生效。
- 每个所选词段只绑定一个具体词义，与当前成分用词的单选语义一致；同一词在句中不同位置可绑定不同词义。
- 候选范围沿用成分用词：已发布且可引用的词条，并按当前按钮严格限定单词或短语。词形遵循管理员的方言偏好；已有非偏好侧关联仍可查看和解除。
- 查询失败、无候选或目标已下架时保留现有关联，允许清除；不能把查询失败当作取消选择。
- 短语关联在同一个面板内按「短语 → 成分用词 → 词形 → 词义」逐级展开；不在下方重复堆放成分入口，不提供「短语本身」。未配置可用成分的短语不可选择，并说明原因。

### 保存、编辑与关联优先级

- 关联随所属释义/例句保存，重新打开草稿后恢复原词段、词形、词义；发布后可回看，预览也应展示关联。
- 关联属于某条正文的具体位置，不按字符串全局合并。两个 `mother`、两条释义、英美两侧正文互不串联。
- 在关联词段外增删文字时，能确定位置的关联随文本移动；修改关联词段本身时提示该关联需要重新选择，不继续指向错误文字。
- 文本与其关联状态应一起撤销/重做。切换释义方式或方言形态将丢失内容时，应明确提示并允许取消。
- 例句中人工指定的关联优先于重叠的自动关联，未人工指定的部分保留现有自动解析。清除人工关联表示恢复默认解析，不额外新增「永久禁止自动关联」状态。
- 例句已有的主词义关联、权限、草稿版本冲突以及发布校验继续有效。

## 已核实的能力限制

- 已有编辑器、连读/停顿标注、音色及语速配置可以复用。
- 释义没有可写入的正文关联字段；例句的自动关联结果也是只读，完整功能需要后端配套。
- 现有前端已有音频上传入口，但所核对后端尚无相应 `audio_assets` 字段。本次沿用现有能力开关与不可用提示，不补充上传后端。

## 已确认的产品边界

- 中文保留文字编辑，英文词段关联及英美音色用于英文内容。
- 用户再次确认中文释义和汉语译文均不增加编辑器，截图中的中文项是误选。
- 新建关联使用「单词 → 词形 → 词义」或「短语 → 成分用词 → 词形 → 词义」；既有直接短语关联在用户明确清除前保留。
- 音频上传沿用原能力开关，不扩展上传后端。联调时关闭未支持的上传能力。
- 关联单选、人工优先；清除恢复自动解析，不新增自动解析黑名单。
- 提交、推送及部署不属于本次授权。
