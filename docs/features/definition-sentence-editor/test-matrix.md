# 风险验证设计

2026-09-07，编写测试代码前完成。实施依据 requirements.md / design.md 的已确认方案。

| 场景           | 输入与前置                                          | 可观察预期                                                                               | 验证层            |
| -------------- | --------------------------------------------------- | ---------------------------------------------------------------------------------------- | ----------------- |
| 工具替换       | 语法区域、释义、例句各一份编辑器                    | 原语法工具仍可用；另外两处是关联单词和关联短语，其余工具可切换                           | 组件              |
| 工具 Popover   | 点击关联按钮，再在正文连续点选源词                  | 提示及继续按钮均在上方 Popover 内；选词保持展开，进入候选后收起                          | 组件/浏览器       |
| 关联互斥       | 已有单词/短语关联，在另一种模式点击被占用的词       | 只查看和清除原关联，不加入新选择、不查询候选、不允许覆盖；清除后可重新关联，其他位置保留 | 组件/浏览器       |
| 单词目标选择   | 单词模式点击源词，接口返回混合类型候选              | 始终仅一个源词，请求 kind=word，仅展示单词，三级级联选叶子生效                           | 组件/API          |
| 短语选词       | 普通点击多个源词、取消选词、跨段点击、切换模式      | 无需组合键；未确认不查询；至少两个词才可继续；禁止跨段；切换重置                         | 组件/浏览器       |
| 短语目标选择   | 完成多选后点击选择关联短语，接口返回混合类型候选    | 请求 kind=phrase，仅展示短语；无短语本身；无成分短语不可选                               | 组件/API          |
| 短语成分       | 目标短语存在成分用词                                | 可选成分后关联其词形词义，保留可验证的短语来源                                           | 组件/后端         |
| 重复词与区间   | 重复 mother、emoji、跨行、dress … up                | 码点准确；独立位置互不串联，不吞中间未选词                                               | 纯函数/浏览器     |
| 修改与撤销     | 区间前插入、词段内部删除、撤销/重做                 | 确定的区间移动；失效关联清除并提示；历史整体恢复                                         | 组件              |
| 方言与语音保存 | 两处各有 common 或 uk/us，voice_profile、连读和停顿 | 保存请求与重新读取完整保留，不覆盖另一侧                                                 | 模型/handler      |
| 只读及失败     | 禁止编辑、检索错误、目标已归档                      | 不触发写回，不因失败清空，已存关联仍可显示                                               | 组件              |
| 输入校验       | 越界/伪造 surface/重叠区间/错误目标归属/自引用      | 拒绝保存并定位源正文                                                                     | Rust 单元/handler |
| 旧客户端       | text_links 省略；未改正文和改正文两种               | 前者保留、后者明确拒绝；显式 [] 才清除                                                   | Rust              |
| 发布与引用     | 保存后发布、查看发布、切换发布；目标词义被引用      | 链接不丢失、快照正确、删除目标受保护                                                     | 隔离数据库        |
| 自动与人工     | 同范围自动命中 + 人工指定另一义；清除人工           | 人工优先，清除后恢复自动规则，段间词保留                                                 | Rust              |
| 契约兼容       | 新字段为空/有值、能力位缺失、旧后端响应             | 新前端可读旧响应；不向旧后端发送新字段                                                   | API client        |

沿用原有成分用词测试守住提取回归；每轮只运行改动涉及的测试，完成前统一运行两仓所需质量门。
