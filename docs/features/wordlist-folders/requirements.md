# 我的词表：双目录与回收站

## 目标与范围

2026-10-16 用户确认：C 端「我创建的」和「我收藏的」分别拥有独立的文件夹系统与回收站；删除文件夹时内容一起进入回收站，可以恢复。先整理需求和技术设计，再实现。本任务包含前后端本地实施和验证，用户后续已授权检查、提交、推送并分别开 PR；未授权合并或部署。

每套系统的根目录可放文件夹和词表，支持子文件夹。目录、移动、搜索、回收站均按用户和系统隔离；两套系统不可互相移动。每份自建词表或收藏引用在对应系统中只有一个位置。历史数据迁入各自根目录。

## 操作与交互

- 保留「我创建的 / 我收藏的」入口；路径导航可返回上级或根目录。回收站是固定入口。
- 文件夹支持新建、重命名、移动和删除。文件夹排在词表之前，同类按名称排序。
- 自建词表可在当前目录创建、打开编辑、重命名和移动。收藏时选择收藏系统的目标目录；重复收藏定位已有项目，不复制。
- 收藏引用原作者最新公开内容；支持个人备注名，不改原作者标题，仍展示原名与作者。不可用时只展示用户自己的备注及不可用提示，不泄漏原作者已撤回的内容。
- 多选文件夹和词表后批量移动或删除；桌面拖拽与「移动到」菜单使用同一逻辑，移动端使用菜单。
- 搜索覆盖当前整套系统，显示所在路径并能定位目录；普通搜索排除回收站。
- 名称去除首尾空白后为 1–100 字。同目录文件夹不能重名；词表可以同名。目录深度最多 20 层，拒绝移入自身或后代。

## 删除与恢复

- 删除前展示本次影响的文件夹和词表数量；批量同时选择祖先和后代时只计算一次。
- 删除文件夹，将当前正常状态的整个子树一起移入回收站，保留层级。先前单独删除的项目属于独立删除批次，不随父目录一起恢复或永久删除。
- 回收站按顶层删除项目展示，可进入已删除目录查看内容。支持整树恢复以及单独恢复其中一份词表。
- 默认恢复到原父目录；原父目录不存在或仍在回收站时默认恢复到根目录，也可选择本系统内其他正常文件夹。
- 恢复发生文件夹重名时添加「（恢复）」及必要序号，不覆盖、不合并。
- 收藏删除只作用于本人收藏记录。恢复仍引用原词表；原词表不可用时保留不可用提示。
- 自建词表进入回收站时停止公开访问、推荐、继续编辑和新增收藏；取消未决审核。别人已有收藏保留并显示不可用。恢复为私密草稿，重新公开遵循现有人工审核流程。
- 保留学习任务、学习历史与历史收益。被删除来源依照现有学习可用性规则不可再使用，不复制旧题内容绕过权限；恢复不使已失效的公开题目重新有效。
- 不自动过期清理。支持确认后的彻底删除及清空本套回收站；永久删除后不可恢复。自建词表保留必要的历史引用墓碑与既有审计/学习记录，移除用户内容和恢复入口。

## 可观察验收

1. 两套系统独立建同名目录；跨系统/跨用户移动、恢复和读取均失败，不能探测对方名称。
2. 在子目录创建词表或收藏后刷新、重新登录，位置与内容一致；旧入口创建仍进入根目录。
3. 移动整树保留 ID、内容、收藏关系及学习历史；循环、重名与过期页面提交不会造成部分写入。
4. 目录删除包含全部正常后代；删除前已在回收站的项目独立保留。刷新回收站可查看结构、单项或整树恢复。
5. 原父目录失效时恢复到根目录；重名自动改名；重复请求不重复创建、恢复或计数。
6. 自建公开词表删除后公共接口不可读、旧编辑不可写、待审不可通过，其他用户收藏显示不可用；恢复后仍私密。
7. 收藏删除/清空不影响原作者内容；恢复不可用引用不恢复公开权限。
8. 多选和拖拽与菜单行为一致；小屏、键盘操作、空态、加载与错误可用；失败后不假报成功。

技术方案与剩余工作见 [design.md](design.md)。

## 已确认的工作区布局（2026-10-16 补充）

用户要求类似代码编辑器的排版：左侧为工程目录区域，右侧为内容区域。桌面使用双栏工作区；左侧以可展开树展示当前系统的文件夹和词表，保留两套系统切换及回收站入口。点击文件夹在右侧管理目录内容；点击词表在右侧阅读，切换编辑也留在工作区。新建词表同样在右侧进行。编辑中切换目录、词表或退出时，沿用未保存确认，不能静默丢失输入。中小窗口按输入设备切换目录浮层或抽屉，具体规则见下方补充。调试验收优先使用 Codex 内置浏览器。

### 左侧资源管理器细化

2026-10-16 用户要求左侧更接近 VS Code：桌面使用约 28px 的紧凑连续行、缩进线、展开箭头、文件夹/词表图标和选中条；顶部提供新建词表、新建文件夹、刷新、全部折叠；项目支持右键及悬停菜单。新建子目录绑定被操作文件夹，菜单复用既有重命名、移动、删除/恢复能力。目录宽度可拖动调整（200–420px），分隔线也可用方向键调整；目录支持上下键切换焦点、左右键展开/收起。两套目录和回收站规则不变。

### 中小窗口目录展示

用户确认：可用宽度至少 1024px 时为常驻可调宽侧栏；不足 1024px 且支持精确鼠标悬停时，收为「目录」按钮，悬停 150ms 展开浮层、离开 250ms 关闭，点击按钮或固定按钮可保持打开。鼠标移入目录的右键菜单时不关闭，Esc 先关闭菜单，再关闭浮层。触摸/无精确悬停能力时，点击打开左侧抽屉，背景不可操作且锁定滚动；展开文件夹不关闭，选中词表或新建词表后收起。支持关闭按钮、遮罩和 Esc。

三种展示方式共用同一棵目录树，切换时保留展开、选中和滚动状态，不能清空右侧未保存输入；关闭抽屉后返回目录按钮焦点。
