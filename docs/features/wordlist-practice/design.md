# 所有可访问词表参与自主练习

## 目标与范围

用户要求自己创建的私密词表也能练习，不再因自定义来源或等级等内容筛选而整张词表无法出题。保留原有词表访问权限、账号权限和任务配额；不开放他人的私密内容，不从空词表凭空生成题目。

复用词表目录、任务、覆盖轮次、题目快照、首次判分和完成进度。新增自定义词来源，使用真实 `item_id`，不冒充平台词库 ID。平台内容优先沿用现有适配释义；不适配时使用词条已有释义和词形。自定义词使用作者填写的词面和释义，不编造词性或释义。

用户已确认：单选选项不足时自动改为拼写题。按题保留可用的单选，其余内容使用拼写；开练时选项减少也可回退。

## 实现与数据边界

- 后端任务 checkout：`wordlist-practice/tsz-rust`；前端复用 `private-wordlist-practice/tsz`。
- `learning_questions` / `learning_cycle_units` 增加自定义来源标识，平台专属标识允许为空，并用约束保持来源互斥。历史平台题不变；down 遇到自定义题或新版本轮次/批次时明确拒绝，避免丢失身份或退回不支持其判分的实现。
- 自定义题保留创建时的词面/释义快照；当前来源的项身份、membership 和内容均匹配才能继续。删除、改词或无权访问后不能泄漏旧内容；复用既有运行中删除宽限。
- 自定义项先复用任务进度，不写入以平台义项为身份的记忆复习模型。平台既有合格题仍沿用原记忆规则；为保证可练而补充的题不制造平台掌握度。
- 改词、移除再加入、词表撤回/删除、跨账号访问和幂等重试是主要回归风险。

## 验收

1. 纯自定义私密词表能预览、创建、答题、完成；重新 GET 保留进度，答前不泄漏答案。
2. 混合词表保留两种来源及稳定身份；等级不适配不再使已有内容整项落空。
3. 非所有者不能练习私密表；内容变更后旧题不能继续，已有学习事实保留。
4. 迁移往返保留历史平台题，自定义题存在时拒绝破坏性回退。
5. 定向后端、前端及契约检查；独占本地 Postgres/Redis + Web production build 验证真实链路，结束清理本批次资源。无 OSS 操作。
