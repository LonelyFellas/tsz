# 新版短语成分用词

新版词库在短语的每条词义内恢复「成分用词」。每个用词可以选一条具体词义，允许关联新版词条或 V1 词条。草稿与发布预览显示已保存的词面和词义。短语拼写改动后，旧词面上的关联仍可查看和清除。

- 新版候选按当前媒介语言、拼写和英语地区匹配。已有词库读权限即可搜索，词条修改仍由原有编辑权限和草稿版本控制。
- 词义按稳定 ID 保存对应关系。请求省略 `component_usages` 时保留原值，提交空数组时清除。发布前重新校验关联，目标须有可用的发布版本。
- 服务端通过 `x-tsz-next-component-usages: v1` 协商响应字段。旧前端继续读取与保存原有格式，新前端连接旧后端时隐藏编辑入口。
- 草稿及发布快照读写使用既有 JSONB，新增关联写入后，旧后端的严格草稿反序列化会拒绝新增字段。发布时先验证旧前端与候选后端的组合，再更新前端的后端契约目标至实际合并提交。回退时保留支持本字段的后端版本。

本地验收覆盖选择具体词形与词义、保存、重新打开和清除。真实接口同时覆盖未协商的旧客户端保存、无效目标、仅具读取权限的查询以及目标未发布的发布预检。
