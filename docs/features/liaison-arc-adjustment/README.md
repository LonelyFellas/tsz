# 连读弧微调

后台编辑器的「微调连读弧」独立于连读添加和清除模式。可点击弧线或在列表中选定一条，再分别上调或下调左右半弧。两端锚点与两半的连接点固定；调整一边不改变另一边。每次调整及「恢复自动」可撤销，跟随原草稿保存。编辑和只读使用同一条路径算法。

## 富文本契约

V2 富文本的 `liaison` 注解在通用和 V3 DTO 中接受两个可选整数字段。缺省值为 0，序列化省略零值，恢复自动移除两项。

| 字段               | 取值            | 含义                                     |
| ------------------ | --------------- | ---------------------------------------- |
| `left_offset_pct`  | `-100` 到 `100` | 左半弧在可调高度内的偏移百分比，正值向上 |
| `right_offset_pct` | `-100` 到 `100` | 右半弧在可调高度内的偏移百分比，正值向上 |

`start`、`end`、`start_len`、`end_len` 仍决定锚点和去重，重复时保留第一条。同一行的路径保留字形留白、停顿避让和弧高上限。软换行显示默认半弧，回到同一行后恢复存储的偏移。显式段落换行继续遵守原注解校验。语音合成及试听缓存以移除偏移后的内容计算，V3 草稿和发布快照保留偏移。无需数据库迁移。

## 配套兼容

| 组合                          | 结果                                     |
| ----------------------------- | ---------------------------------------- |
| 旧前端 + 新后端，数据没有偏移 | 后端输出原形状，旧严格 schema 可读取     |
| 新前端 + 旧后端               | 旧内容可读取，保存调整会因未知字段被拒绝 |
| 新前端 + 新后端               | 可保存和回读调整，旧内容继续按自动弧显示 |
| 旧前端 + 新后端，数据已有偏移 | 旧严格 schema 会拒绝新增字段             |

后端先上线并确认所有实例已接受新字段，再更新前端消费者并切换写入。新数据写入前确认所有读取方已支持新字段，包括仍打开的旧后台页面或旧版本客户端。写入后需保留兼容读写版本。若必须退到旧版本，需先有经授权的快照备份及字段兼容或数据处理方案，范围包括草稿、发布快照和其他持久化副本。

## 验收

使用 `intermediate` 的四条原音标和一条软换行样例核对默认弧、固定端点、单弧微调、撤销、恢复自动、跨行回退和只读路径。原数据只作对照。

2026-11-26：本地隔离后台以 `intermediate` 四条原音标为基线，分别上调、下调第一条的左右半弧。两端和半弧连接点不动，调整一侧时另一侧路径不变。真实保存并刷新后，GET 回读左右偏移 `30`、`50`，编辑和只读路径各自与刷新前一致，另外三条未改变。再次恢复自动并保存，GET 确认两项偏移均省略。未改测试服原词条。
