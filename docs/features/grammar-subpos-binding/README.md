# 新智能词库语法结构

目标入口为 `/lexicon-next`；旧 `/words/.../v3/wizard` 保持主线行为。新入口复用原有富文本标注控件，按目标语言切换独立维护英式、美式文本；一条结构绑定一个细分词性，两侧共用绑定，一个细分词性可有多条结构。同文不同分类不合并。AI 与未开放的审核／发布不在范围内。

## 验收

- `NextDraft.grammar_structures`、`NextSense.sub_pos`、`NextDefinition.grammar_structure_id` 均为兼容存量的可选字段。缺字段保留原语义，不猜测回填。
- 结构按基本词性管理，释义候选按义项的细分词性筛选。结构／义项改绑保留失效引用并提示；草稿允许暂缺或保留待修复绑定，服务端语言预览返回具体问题，错误关联不投影成有效语法。
- 跨基本词性的细分词性、错误／不存在的引用、重复节点、非法富文本及方言被拒绝。删除结构前说明引用数量，确认后仅清除对应引用，释义正文保留。
- 富文本、Unicode 标注、英美两侧、分类与引用保存并独立 GET／刷新一致；取消编辑不影响草稿，其他字段后台更新不被确认弹窗覆盖。
- 本次使用私有 PG/Redis 和独立 API/Admin 进程验证，不创建 OSS；结束清理全部 fixture、凭据、进程及本地临时副本。

## 契约与兼容

新增 `x-tsz-next-grammar: v1` 能力协商。新前端遇旧 API 时能力缺省，保持旧草稿流程，不发送新字段。新 API 向未协商的旧前端隐藏语法／分类／释义引用扩展；存量已含扩展时，缺字段的保存会明确拒绝，防止静默删除。优先前端先发，再发 API，启用后才可写新格式。

migration `20261114130000_lexicon_next_grammar` 扩展永久节点身份类型；语法内容随现有 JSONB revision 保存。down 在出现扩展节点或快照后拒绝回退，不删除历史数据。存在新格式数据时不能直接回退旧二进制。当前新入口 `publishing=false`，本任务不伪造发布验收。
