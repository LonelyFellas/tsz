# 内容编辑与关联权限拆分

## 范围与行为

智能词库和多维例句分别提供内容编辑、单词与短语关联、可编辑他人三个权限项。继续使用 `words.edit` / `sentences.edit` 表示文本、音频及其他内容编辑；新增 `words.associate` / `sentences.associate` 表示正文内关联。每个模块的 `edit_others` 共用且仅扩大已授予动作的归属范围，不隐含任何编辑动作、发布或生命周期权限。

关联包括词库正文 `text_links`、语法 `form_links`、共享例句 `annotations`。词条结构、关系词条列表及短语成分结构仍属于内容编辑。新增内容继续服从原创建权限。

存量有效编辑授权和权限标签补授关联权限，保留原能力。迁移递增受影响账号和标签的版本。独立关联用户可以进入现有内容，选择关联目标并保存；文本、音频、等级、译文及结构保持不变。无关联权限时不能添加、替换或清除关联；修改正文导致关联变化也需关联授权。
