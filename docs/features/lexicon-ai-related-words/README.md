# AI 拓展词优先使用智能词库

生成派生词、近义词和反义词前，Rust 从同一媒介语的已发布智能词库检索候选词义。检索复用当前词条发布时的关联、内置词典记录的关联词面和派生词的词面线索。Agent 结合当前词义挑选适用的内部候选，再补足有语义依据的外部候选。

Rust 校验候选的规范化词面和媒介语释义。同组释义短语可以换序或换用列举标点。候选必须唯一匹配到当前发布且草稿仍保留的词义，才会返回稳定词条和词义 ID。预览优先显示内部候选并标记「智能词库」。「一键配置」采用已验证的关联，其他候选使用待关联文本，保留已有草稿内容。保存使用已有拓展词权限和关联校验。

生成及候选回读使用 `x-tsz-next-relation-targets: v1` 协商可选的 `target`。旧后台接收原响应形状，新后台也接受旧 API 返回的待关联候选。Agent 沿用现有参考资料结构，无数据库迁移。

用独立本地词库验证同媒介语已发布派生词优先进入预览，应用并保存后重新请求可读取实际关联 ID。不同媒介语、归档、释义歧义和目标词义已移除的候选保留待关联文本。
