# 公开词表付费查看：功能需求与评估

日期：2026-10-17。当前阶段：**需求评估，暂不继续实现**。本文是前后端共用的主记录。用户最新决定：本期购买成功后不支持退款，不提供用户退款入口；此前人工退币、平台兜底及退款后撤权方案已取消。其余已确认规则继续适用。此前本地代码属于未完成初稿，不能作为本文需求已实现或功能已交付的证据。

配套 [前后端技术设计](paid-unlock-technical-design.archived.md) 已梳理版本留存、学习权限、购买事务、接口和迁移验证；属于设计稿，尚未实施。本文仍为产品需求与当前状态主记录。

## 1. 目标与已确认规则

用户可收藏别人的公开词表，但收藏不授予完整查看权限。未购买时只预览前 5 个词条，其余模糊展示；支付天生币后获得完整查看权及学习使用资格，仍不能编辑原词表。

| 事项       | 已确认规则                                                      |
| ---------- | --------------------------------------------------------------- |
| 应用范围   | C 端公开详情页和收藏详情页统一执行，前后端共同限制              |
| 预览数量   | 固定为作者保存顺序的前 5 个词条                                 |
| 定价       | 作者在 1–100 天生币内设置整数价格（含两端），不开放免费作者词表 |
| 收益       | 购买金额全部进入作者天生币钱包，不抽成                          |
| 购买有效期 | 成功购买永久解锁，包含后续更新，不按次或按期收费                |
| 权限性质   | 可完整查看并用于学习，不获得编辑权或词表所有权                  |
| 学习门槛   | 未购买的他人词表不能用于学习，购买后才能使用；不开放前 5 个试学 |
| 撤回与删除 | 作者撤回或删除词表后，已购用户仍可查看并使用最后公开版本学习    |
| 收藏       | 收藏与购买是独立关系，收藏不会自动解锁                          |

补充确认：历史平台词表保持免费，可按原规则查看和学习，是购买门槛的明确例外；作者词表未定价时只可预览，不可购买或学习。购买不自动收藏，历史和新打赏均不兑换购买资格；独立购买记录及重新打开入口是必要能力。作者注销或账号停用本身不收回已购查看与学习权；内容违规下架另按平台治理处理。

本期不提供购买退款、后台购买退款审核、平台兜底补偿或退款撤权流程；购买确认前明确告知“不支持退款”。此决定替代此前的退款方案，不改变购买失败时事务回滚、重复请求防重扣及技术故障修复要求。

作者仍可完整查看、编辑和管理自己的词表，自有词表无需自购；本次购买门槛针对他人的作者词表。购买者不得修改名称、词汇、顺序、作者注、价格或公开状态，不得取得作者私密备注；是否是教师不改变词表归属。

本轮交付终点是功能需求文档和评估结论，不包括继续实现、提交、推送、PR、合并或部署。

## 3. 查看权限与预览规则

以下权限及预览规则均已确认；“已购”指服务端已成功成交的购买。历史平台词表按免费例外处理，平台治理限制优先于保留版本访问；本期不通过退款撤销购买资格。

| 使用者       | 尚未购买                           | 购买之后                                                               | 编辑原词表           |
| ------------ | ---------------------------------- | ---------------------------------------------------------------------- | -------------------- |
| 游客         | 预览，购买前登录                   | 不适用，资格归登录账号                                                 | 不可                 |
| 登录的非作者 | 预览，可收藏，可购买，不可用于学习 | 完整查看并获得学习资格；作者撤回或删除后仍可查看并使用最后公开版本学习 | 不可                 |
| 作者本人     | 完整查看，无需购买                 | 不允许自购                                                             | 仅按现有状态规则编辑 |
| 管理员       | 沿用后台审核/管理权限              | 不依赖 C 端购买资格                                                    | 不因购买扩张管理权限 |

- 前 5 个按作者保存顺序确定。不能通过搜索、排序、翻页、标准/完整模式切换换出另一批可见词汇；接口限制发生在搜索、排序和分页之前。
- 预览显示词条正常阅读内容，但不包含作者私密备注。第 6 个起使用无真实内容的模糊占位，响应、DOM、可访问文本中均不得包含隐藏词条的内容或关联 ID。
- 显示真实总词条数和剩余数量；无需渲染成千上万个模糊条目，显示少量占位即可表达剩余内容。
- 未购买时隐藏全表搜索与排序，保留前 5 个条目的阅读模式。购买后恢复完整搜索、排序和分页，仍按需加载。
- 前 5 个中出现不可用条目时按原位置显示不可用，不用第 6 个及后续词条补齐，避免利用内容状态轮换扩大预览。
- 少于或等于 5 个词条时可完整预览，但仍不具备学习资格。保留购买入口并明确文案为“购买后用于学习”，不能再以“没有隐藏内容”为由取消购买入口或允许免费学习。
- 平台词库中独立存在的公开词条仍按其自身规则访问；本功能保护词表的完整选词、编排及作者内容，不把整个平台词典改为收费。

## 4. 用户流程

### 学习使用规则（已确认门槛）

- 未购买的他人作者词表不得作为学习来源，包括仅含 1–5 个词条的词表；详情预览不是试学资格。收藏、打赏、知道词表 ID 或切换教师身份均不能代替购买。
- 来源选择可展示词表名称、价格和“购买后可用于学习”，但不得开放选择及可出题内容；直接调用创建任务、预览题目、开始新轮等接口同样校验购买资格。
- 现有任务在上线后也必须检查购买资格。不能通过旧任务、已生成题目、继续作答或历史复盘读取未购买词表的学习内容；保留个人学习统计和既有完成事实，不因权限变化清空历史。
- 现有未完成轮次发现未购来源时暂停，不删除题目来凑成完成；来源仍在售时提示购买，已撤回、删除或其他不可售来源则说明无法购买的原因，不展示无法完成的购买按钮；购买后重新检查来源与版本，满足恢复条件才继续，否则按原有规则重开。具体恢复交互在技术设计中确定。
- 多词表任务中出现未购来源时，创建/开轮应明确指出需要购买的词表，不静默移除该来源或缩减题量。
- 购买成功后来源选择、任务创建及后续学习请求应识别持久化资格；不能只更新详情页按钮。购买带来学习使用权，不赋予修改原词表、作者注或作者保存顺序的权利。
- 作者撤回或删除后，已购用户仍可基于最后公开版本创建学习任务、开始新轮、继续已有学习及复盘；未购用户仍不可查看该保留版本或将其用于学习。
- 在其他学习条件仍满足时，不得仅因作者撤回或删除就判定已购来源失效、停止轮次或隐藏复盘内容。已有轮次按原有题目快照和判题规则继续，不静默替换已发题；新任务和新轮使用最后公开版本。
- 任务到期、用户主动归档、账号资格等与作者撤回/删除无关的限制继续生效。作者注销或停用本身不使已购来源失效；平台治理造成的内容限制按下文执行，本期不提供退款流程。

### 作者定价

在「我创建的」词表管理区展示当前价格和修改入口。输入价格 → 校验 → 保存 → 展示保存后的价格。购买者不显示该入口，伪造请求也不能修改。

价格范围固定为 **1–100 天生币（含 1 和 100）**，仅允许整数，不开放小数、负数、0 元购买或免费作者词表。创建价格、改价和成交均由后端校验范围，不能仅依靠输入框。未定价时明确显示“作者尚未定价”，不可购买，不自动替作者定价。价格保存独立于内容编辑：不因改价撤回词表，不改变既有购买资格，也不自动改动待审内容。

并发改价不能静默覆盖；保存结果不确定时重新读取价格再提示。作者可改价，已购买用户无需补差价，资格不受改价影响；作者降价不退差价。后续如平台调整价格范围，仅影响新定价及后续成交，历史订单仍保留原实付金额。

### 购买前的学习可用性

- 购买确认前展示不泄漏隐藏词条、释义或题面的学习可用性信息，例如当前支持题型、可用词条数量，以及所选题型/学习等级下题量不足的提示；未配置学习条件时提示需设置后才能判断，不能伪报“可正常出题”。
- 明确购买解锁查看与学习资格，不保证每个词条均支持当前题型、等级或期望题量。某个用户当前条件下无法出题，与整张词表内容不可用分别提示。
- 全表内容不可用时禁止新购买；状态或可用性读取失败时不能当作可售。成交前再次核验，不仅依赖确认页旧状态。
- 部分内容不可用或当前条件题量不足时，在确认前说明事实，不虚构可出题数量；用户可依据提示决定是否购买。已购用户资格保留，实际学习仍受题型、等级及内容可用性约束。

### 预览与购买

1. 用户从公开页或收藏页打开词表，看到标题、作者、总数量、前 5 个预览及模糊区。
2. 展示明确价格与「购买后永久完整查看并可用于学习，包含后续更新，不支持编辑」。已有收藏状态不改变价格和查看权限。
3. 游客先登录并返回原词表；登录后重新确认价格，不自动扣款。复用现有手机号绑定和账号门禁。
4. 点击购买后确认词表名称和实际支付金额，明确展示“购买后不支持退款”，同时说明学习可用性和永久查看/学习权益；不要把打赏按钮当作购买入口。
5. 服务端按当前价格和购买资格成交。成功后显示已购买、开放完整查看和学习入口并刷新钱包余额；重新打开页面和换设备后仍有效。
6. 余额不足时不创建购买资格，提供钱包入口。价格变化时不按新价格自动扣款，要求重新确认。请求超时先查询已有资格，重复请求不得再次收费。

### 历史数据过渡

- 历史收藏、历史打赏和已有学习任务均不自动兑换购买资格；历史作者词表未定价时按“仅预览、不可购买和学习”处理，平台词表按免费例外保留原行为。
- 上线前向作者和读者说明定价、学习购买门槛及历史任务变化；不默认为作者设置售价，不伪造历史购买记录。
- 历史任务引用未购来源时保留统计和完成记录，停止该来源的继续学习与内容复盘；来源已撤回、删除或无法购买时说明原因，不反复引导用户执行不存在的购买操作。不额外迁移或赠送资格。

### 已购内容的后续使用

本节以服务端已成功成交为前提。

- 购买资格归账号和词表，跟随学生/教师身份切换；不跟随设备，不转给其他账号。
- 取消收藏、删除收藏目录或将收藏放入回收站不影响已购资格；购买不会自动把原词表变成自建词表。
- 必须提供独立「购买记录」及重新打开入口，列出词表、作者、支付金额、购买时间和可用状态；优先复用现有账户布局，不新增第三套文件夹系统。购买不自动收藏；已有收藏保持原目录，取消收藏后仍可从购买记录找到词表。
- 普通词条内容更新及作者重新公开的更新无需再次付款。未公开的编辑稿不能作为“包含后续更新”提前交给购买者。
- 作者撤回或删除后，已购用户仍可通过原详情/收藏入口或购买记录打开最后公开版本，并从学习入口继续使用该版本；不能统一显示“词表不存在”或要求重新购买。未购用户不能利用同一路径读取该版本，也不能新增购买已撤回或已删除的词表。
- 作者账号注销或停用后，已购用户继续查看和学习最后可用公开版本；停止新购买，不能因作者个人数据清理而级联删除已购内容。作者身份展示遵循现有账号隐私规则，不保留不必要的个人信息。
- 平台认定违规并下架的内容停止查看和学习，保留版本和学习历史不能绕过限制。平台词条归档或资源被撤销时，沿用相应内容不可用限制，对受影响内容明确提示；其他正常内容不因作者账号状态单独失效。本期不自动退币或发放平台补偿；购买记录保留，页面明确提示内容受限原因，不以保留版本绕过治理。

### 最后公开版本的定义与保留

- 词表公开期间，选词、顺序、作者注跟随作者最新成功公开的版本；平台词条的释义、音标等正常更新继续生效，未公开草稿不可见。
- “最后公开版本”指词表撤回或删除时，读者实际可见的最后公开编排及其完整内容：同时保留当时已生效的平台词条内容，不只是作者上次发布词表时的旧释义，也不是购买时版本。作者注销或停用导致停止公开时按同一原则留存。
- 保留版本不会在撤回/删除后继续静默追随平台词条正常更新；词表重新公开后切换到新的公开内容。平台违规下架、词条归档及资源撤销的访问限制仍可作用于保留版本。
- 首期不提供历史版本选择。作者发布新版并移除部分词汇后，详情和新任务/新轮使用新版；已有轮次保留原题和判题规则，正常作者更新或移除词汇不改写已发题，不据此撤销已有轮次的合法学习资格。平台治理和任务到期等独立限制继续生效。
- 例如：用户在 V1 购买，作者公开 V2 后撤回并编辑 V3，则购买者可查看 V2，并以 V2 创建任务或开始新轮；V3 未公开前不可查看或用于学习。作者随后成功公开 V3，已有购买者自动获得 V3，后续新任务和新轮使用 V3；之后删除，V3 仍可查看和用于学习。已有轮次保持其原有题目快照，不随版本切换改题。
- 保留内容至少覆盖当时公开的词表名称、有序成员、作者公开注释和完整阅读、出题、判题及学习复盘所需的公开内容与资源引用；不得混入作者私密备注、草稿、待审修改或内部审核信息。快照存储形式留给技术设计，但不能只保存一组指向可能被删除内容的 ID。
- 作者可撤回或删除自己的词表；删除对外可见内容和清理其创编数据时，必须保留已有购买关系对应的查看和学习版本。不能以“禁止作者删除”替代用户已确认的删除后仍可查看和学习的规则。
