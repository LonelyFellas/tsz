# 公开词表免费查看：当前需求

日期：2026-10-17。状态：**本地清理及真实验收完成，文档进入 PR 交付，未发布**。本文件是本任务当前规则的唯一主记录，覆盖此前付费预览、购买解锁及相关交易方案。

## 当前规则

- C 端公开详情页和收藏详情页均可免费完整查看别人的公开词表，不限制前 5 个，不对后续词汇做付费模糊处理。
- “完整查看”仍可使用正常分页、按需加载、搜索和阅读模式，不要求一次返回全部数据。
- 收藏仍是引用原词表的整理行为；免费查看不要求先收藏，也不会复制为本人词表。
- 免费查看不授予编辑权限。词表编辑、排序保存、作者注和公开状态操作仍由原作者按现有权限管理，私密备注不会对外公开。
- 学习沿用现有账号资格、学习设置、任务及来源可用性规则，不增加购买门槛，也不要求历史任务补购。
- 仅当前可访问的公开词表适用；私密、撤回、删除、账号失效或平台治理限制继续按现有规则处理。
- 此前专为“已购用户”设计的最后公开版本永久留存及删除后继续学习特权，不再作为本期需求；不由免费查看推导出对撤回内容的新访问权。

## 本期不推进的能力

作者定价、1–100 币购买、付费预览、购买记录、购买权限、退款或不退款交易流程、平台兜底，以及为已购权益新增的版本/订单/学习权限改造，全部移出本期实施范围。

本次方向调整针对新增的词表交易方案，不删除或改造既有天生币钱包、投币打赏和流水体系。
