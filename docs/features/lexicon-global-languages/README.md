## 数据与接口

- 词条保存不可变的 `medium_locale`，独立于完整多语言草稿正文；新建时传入所选媒介语言。
- 用户批准旧数据迁移：仅有繁体媒介内容的归繁体；简体、空白、同时含简繁的归简体；保留全部正文和历史版本。
- 工作区列表、统计、创建人、垃圾桶和新建匹配按归属查询，空白草稿亦可见；同名标注限定同语言归属。
- 新客户端通过 `x-tsz-next-medium-ownership: v1` 协商新增能力与归属字段。旧客户端继续收到旧响应结构，旧创建请求缺省归简体。
- 编辑已有词条时切换媒介语言返回对应词库，沿用未保存内容的离页确认；不能在另一语言顶部下编辑原归属词条。英美目标变体仍共享英语词条。
- 保存、预览和内容编辑锁阻止同路径历史导航改变语言；新建请求同样锁定上下文。
- 浏览器按管理员账号和目标语言记住上次选择。显式链接参数优先；缺少参数时先恢复并补齐 URL，再加载业务数据。损坏或已不支持的记忆回到当前能力默认值。

## 可观察验收

- 各语言创建空白词条，刷新后只在对应列表、统计、创建人及垃圾桶中出现；删除最后一条媒介内容不改变归属。
- 刷新和离开重进保持上次语言组合；不同管理员不串用偏好，取消离页不覆盖记忆，首次列表请求即使用恢复后的范围。
- 新建匹配不泄漏另一归属的同名词条。切换语言不丢草稿，不回显旧请求的错误语言预览。
- 隔离库验证迁移 up/down、旧数据归属和原文完整性；真实页面创建、保存、重新打开验证持久化并彻底清理本批 fixture。
