## 七组内容与计数口径

| 分组     | 标题右侧       | 明细与规则                                                                                                                                                                                                                   |
| -------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 语言识别 | 完成状态       | 原「方言识别」改名；读取实际语言，显示中文名和英文名。英语区分英美时显示带现有色点的「英式 BrE」「美式 AmE」子行；通用时仅显示「英语 English」，不补「通用」子行。                                                           |
| 基本词性 | 基本词性条目数 | 按当前词形编辑顺序列出真实词性名称。细分词性不重复计入。                                                                                                                                                                     |
| 词形变化 | 派生词形总数   | 按基本词性列数量；排除 `base` 原形。一个具体词形无论被多少词形组使用、有几个地区变体，都只计一条。                                                                                                                           |
| 语义区间 | 全局语义区间数 | 按编辑顺序编号；优先中文文本，否则英文文本；两者皆空显示「待填写语义区间」。                                                                                                                                                 |
| 语法结构 | 结构条目总数   | 按词性列数量；一个结构含英美两份内容仍计一条，不按变体计数。                                                                                                                                                                 |
| 多维词义 | 词义条目总数   | 按词性分组，显示该词性数量；组内从 1 编号显示释义摘要，顺序与编辑卡片一致。沿用词义卡标题的摘要口径：首条定义的有效文本，没有则显示「待填写释义」。一项词义下有多条定义不增加词义数。                                        |
| 多维例句 | 例句条目总数   | 只展示当前草稿实际存在的等级，按 A1、A2、B1、B2、C1、C2 顺序排列，不显示数量为 0 的等级。按例句自身等级统计，不按父词义等级；英美文本、多档译文不重复计数。空/未识别等级仅在实际存在时列为「未分级」，排在最后且不丢失总数。 |

以上数量描述草稿中已有条目，包含刚添加的待填写条目；不等于合格条目数。同一文本出现在不同词义的不同例句条目中，仍按各条目计数，不按文本去重。

基本词性和各词性数量保持对应：无派生词形、语法结构或词义的已选词性显示 0。空列表显示「暂未添加」，不使用示例内容补位。长语义文本和释义以单行省略号显示，悬停可查看全文；完整数据不截断或回写。

## 语言与类型边界

- 展示名由当前 `language` 推导，不在组件中无条件写死英语；使用语言名称映射，未知名称显示实际语言代码或「未识别语言」。
- 当前 V3 权威前端契约仅接受 `en`。本次不扩大后端支持语言、不放宽运行时契约、不增加语言选择器；将来新增合法语言时，摘要可读取它的名称，不把它错误显示为英语。
- 英美子行反映当前草稿词性的拼写/发音类型配置，不能根据两个单词拼写是否相同来判断。任一有效词性明确区分英美时显示两种类型；全部通用时不显示子行。词性尚未建立时不凭空制造类型识别结果。
- 复用现有 `dialect-dot-uk / dialect-dot-us` 标记，不使用新图标或自定义颜色体系。

## 实时与完成状态

1. 优先读取当前未保存的词形、词义草稿，四步来回切换显示相同内容；普通保存失败或版本冲突时仍展示保留的本地草稿。
2. 文字输入、增加/删除、排序、变更等级或词性后，在同一次状态更新中同步摘要；只刷新界面派生值，不发校验/保存请求。
3. 「有条目」不自动打完成勾。完成判定沿用现有后端 `completed_steps`；对应步骤有未保存编辑时，暂用原未完成圆圈呈现，并以说明表达「编辑中，完成状态待确认」，不把旧完成结论冒充为当前草稿校验结果。
4. 尚未完成时，语言识别右侧不得固定显示「完成」。服务端确认完成、且相关草稿未再修改后恢复完成勾。选填区块数量为 0 不自行推翻服务端合法完成结论。
5. 本次不另建全套逐字段完成校验，不改变步骤可达性、发布门禁、当前词性 Tab 未填数量及后端错误展示。

## 验收重点

1. 真实草稿增加一个非原形词形、语义区间、词义和例句时，总数及对应分组立即变化；删除与排序也同步，过程中无新增网络请求。
2. 英美双变体结构只计一条；词形多组共享不重复计数；多档译文不重复统计例句。
3. 修改首条定义、语义区间文本和例句等级，不保存即可在左栏看到变化；跨回第一步结果不退回服务端旧内容。
4. 通用英语仅一行语言名称，英美区分显示两子行；未知语言/空内容不被伪装成英语或已完成。
5. 总数等于当前可见等级小计之和；未出现的等级不显示，全部无例句时显示摘要空态；长文本、空值和实际存在的未分级例句均有确定表现。
6. 未保存修改不会显示未经确认的完成勾；原有七组点击定位、只读状态和保存失败后的本地草稿保留有效。
7. 桌面/窄屏视觉与参考层级一致，明细可达，无横向溢出。
8. 左栏只有返回入口与详细完成情况摘要；全页标题/面包屑保留词条名称，返回行为及未保存保护不变。
