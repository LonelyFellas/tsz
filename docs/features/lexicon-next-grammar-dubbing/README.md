# 新词库语法结构配音

目标：让新词库语法结构复用配音中心的 grammar 板块推荐、共享语音编辑器、正式生成及录音资产。保留现有细分词性绑定、富文本标注和本次行内样式；不引入旧词条身份或词形关联。

## 实现与验收

- `NextGrammarVariant` 保存可选 `voice_profile`、`audio_assets`；使用现有 JSONB 草稿，不新增表或迁移。复用配音配置的安全校验、合成源校验及新词库音频引用登记，录音元数据从资产登记回填。
- 以变体自身 locale 确定配音口音，不能由当前界面选择覆盖通用变体。英美分栏各自编辑，通用变体允许两侧配置。
- 编辑期间正文、配音及录音均留在局部草稿；完成一次性回写，取消不改宿主。复用已有权限及语音开关。
- 新客户端协商 `x-tsz-next-grammar-audio: v1`。旧客户端读取时省略音频扩展，旧写入按稳定变体 ID 保留既有配置；正文改变时必须使旧合成引用失效。新客户端连接旧 API 时不开放配音写入。
- 验证：保存后独立读取/重开保留配置；非法配置、伪造/他人/跨词条音频引用失败；词形与语法资产同时保留，删除语法不删除词形引用；失败与取消不丢输入。
