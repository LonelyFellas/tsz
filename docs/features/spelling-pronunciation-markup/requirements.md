# 词形拼写与实际发音标注需求

状态：已完成本地实现，验收记录见 [verification.md](verification.md)。2026-10-09。

## 目标与已确认范围

词条 V3 后台编辑中，词形拼写支持斜体和连读；实际发音只支持连读。
两类字段提供逐条清除连读、清空标注、撤销和重做，完成后应用本次编辑，取消后保留原值。

依据为本次提供的「词形拼写 和 实际发音」原型图及用户确认：

- 「文本设置」限定为词形拼写斜体，不新增字号、颜色或加粗操作。
- 本次完成后台录入、保存和预览；C 端展示另行评估。
- 图中的停顿和音色区不作为本次新增功能，沿用独立合成配置。
- 视觉遵循后台 antd 体系；原型只作为功能参照。

## 用户操作

1. 词形拼写保留未录入时直接输入的路径，并增加与实际发音一致的编辑器入口。
2. 正文始终可以输入或选择。未选中文字时，斜体、连读起点及一次性添加禁用；正文编辑、撤销和清除已有标注不依赖选区。
3. 拼写选区可以设置或取消斜体；部分取消只移除选区内斜体，保留区间其余部分。
4. 连读可以分两次选择起点、终点，也可以选中一段至少两个码点的文字后一次性连接首尾。两端可以包含多个连续字符，复用现有合法性规则。
5. 仅选择起点不保存半条连读，也不能完成编辑；取消起点或完成有效连读后恢复可完成状态。
6. 点击工具不丢失正文选区。实际发音不出现斜体、语法分类、停顿、音色或上传工具。
7. 清除模式持续生效，点击已有连读逐条取消；不删除正文，也不移除拼写斜体。再次点击、切回正文编辑或按 Esc 退出。
8. 拼写斜体通过选区斜体按钮取消；清空标注一次移除本字段的斜体和连读。实际发音清除沿用现有历史标注保留规则。
9. 撤销与重做覆盖正文、斜体、连读和清除操作。取消编辑放弃本会话修改；完成仅应用到向导本地表单，服务器保存仍走现有保存动作。
10. 只读字段不能改正文或标注。失败或修订冲突保留人工输入，不宣称保存成功。

## 保存与回显

- 保留 `spelling` 作为拼写事实，用于搜索、表面匹配、引用和合成来源。
- 新增可选 `spelling_rich` 保存展示标注；它的正文必须与最终保存的 `spelling` 完全一致，允许的标注仅为 `italic`、`liaison`。
- 新字段使用现有 `RichTextV2V3`（JSON 的 version 为 2），不引入 V1 拼写标注。偏移为 Unicode 码点，复用当前范围、跨段、端点与总量约束。
- 没有新字段的旧记录按无标注拼写打开，无历史数据回填要求。
- 已有 rich 值清空标注时发送显式空标注正文；省略字段不是清除指令，`null` 不合法。
- 普通正文改字必须同步处理标注：保留未受影响区间，移除失效标注并给出提示，可撤销恢复。不可只更新纯文本而遗留旧偏移。
- 后端规范化改变文字时，不能只替换 rich 正文而保留旧偏移。界面完成前处理规范化，后端再校验正文一致性。
- 后台字段收起态、发布预览和历史发布内容都能回显拼写斜体与连读；标题、候选和搜索标签继续使用纯文本。
- 沿用现有 ID、权限、修订、发布和引用保护，不通过重建节点绕过约束。

## 英美规则

- 通用拼写只编辑一份 rich 值。
- 拼写统一、发音区分的英美变体，拼写正文和 rich 标注同步更新，发音仍分别维护。
- 拆分通用词形时，拼写与标注一起复制到对应侧；合并时标注随选定拼写来源迁移。
- 两侧标注不一致时，不自动取英式值覆盖美式值。沿用现有合并拦截方式，提示先统一需要保留的标注再切换规则。
- 新建另一具体词形不自动继承模板的展示标注。

## 验收标准

| 场景                           | 可观察结果                                                   |
| ------------------------------ | ------------------------------------------------------------ |
| 未选区、选区及工具点击         | 相关按钮启用状态正确，选区不丢失，正文继续可编辑             |
| 分步与一次性连读               | 只保存有效完整连读，多字符端点保存重开保持一致               |
| 拼写斜体与连读重叠             | 两者同时回显，部分取消斜体不影响连读                         |
| 清除、撤销、重做、取消         | 正文保持正确；标注可恢复；取消不改变原表单                   |
| 正文改字与规范化               | 未改片段保留；失效标注明示移除；无错位或静默保存             |
| common、uk_us 与统一拼写       | 不遗漏任一调用分支；统一同步；拆合不丢标注                   |
| 草稿保存、刷新、发布、历史读取 | 完整 rich 值保留并正确显示；仅改格式也计为未保存修改         |
| 严格契约及非法输入             | 旧记录兼容；拒绝 null、正文不一致、越界和不支持的注解        |
| 普通整表保存                   | 不编辑拼写时不丢标注；有值清空通过显式空标注生效             |
| 纯格式改动                     | 搜索、合成及引用的拼写事实不变；修订和确认凭据按现有规则失效 |
| C 端词单投影                   | 不新增字段或改变现有拼写展示                                 |

本次工具范围及展示范围已按用户确认实施。已验证与尚缺的真实环境证据分别记录在 verification.md。
