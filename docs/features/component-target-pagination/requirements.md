# 关联候选完整分页

用户已在本会话批准评审方案后要求实施。适用于后台成分用词、多维释义与多维例句共用的候选级联。

- 每批请求 50 条候选，存在 next_cursor 时显示「加载更多」。候选不是去重词条数，同词条可跨页。
- 1000 个匹配词条可以遍历，不受原 200 词条/2000 词面窗口静默截断。
- 空首批（被自身/方言等过滤）仍能加载下一批；加载失败保留已有结果，可重试。
- 词库更新导致游标失效时提示重新加载，保留宿主已有选择。换词面或关闭组件后旧请求不能覆盖新状态。
- 短语成分已知目标 entry_id，查询直接限定目标，不在同名词条首批中碰运气；目标内部候选也支持完整读取。
- 不改关联语义、发布权限或单选规则，不修本次无关的 HTTP UUID 问题。用户随后确认区块顺序为「多维释义 → 成分用词 → 多维例句 → 拓展词」，纳入本次前端交付。
- 验收：大结果全集遍历、跨页合并与稳定身份、页请求重试、游标失效、过期响应、定向查询及混合版本约束。

后端验收命令（配置隔离 PostgreSQL/Redis 后）：`SQLX_OFFLINE=true cargo test --locked --test lexicon_handler component_target_search`
