# TASK#59：关联候选词形顺序

任务：http://47.121.142.19/zentao/index.php?m=task&f=view&taskID=59

## 目标与范围

关联场景展示的词形顺序应与目标词条编辑页配置一致，包括多维释义、多维例句、共享例句和短语成分；关联词的独立搜索入口同时核查。这里的顺序是词条词形组及组内成员顺序，不是全局词形类型字典的 sort_order。

- 按词形组顺序、组内成员顺序展开；同一 form_id 跨组共享时首次出现优先。
- 未入组历史词形保留在末尾，沿用原数组顺序，不改变候选集合。
- 方言过滤和同拼写展示合并后仍保持相对顺序，不额外置顶原形或命中项。
- 不改变搜索相关性、词义顺序、已有绑定 ID、选中项及发布身份。
- 沿用版本语义：未发布目标来自草稿，已发布目标来自发布快照；刷新候选后生效，不承诺跨页面实时推送。
- 关联词的词条/词义选择器不新增词形层，不改变关系数据模型。

## 验收

1. 创建顺序与组内顺序不同，候选必须按后者展示；组内调序后重新读取能反映新顺序。
2. 多组共享词形只出现一次，历史未入组词形不丢失。
3. 草稿、发布目标执行相同规则；排序不改变变体、原形集合或可关联词义。
4. 原形命中但配置在末尾时不得置顶；过去式与过去分词拼写相同也不能跨词形合并。
5. 英美筛选/合并及已有非偏好侧关联回显不破坏顺序、选中身份。
6. 相关前端关联与分页回归保持通过；真实页面到数据库联调另行明确记录，不以 mock 测试替代。
