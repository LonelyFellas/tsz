# 智能词库全库批量命题

## 目标与范围

后台完整检索当前有效的已发布教学词义，按一个或多个学习等级和英美档位预览缺题并创建持久化批次。只生成待审核草稿，沿用人工编辑、审核与 Agent。禁止自动全库付费生成、线上数据修改及部署。

前端工作区：`/Users/darwish/.codex/worktrees/question-bank-batch/tsz`（基线 `16399b6`）。后端工作区：`/Users/darwish/Dev/tsz-core/.worktrees/backend/question-bank-batch`（基线 `685c737`）。Agent 沿用现有服务，不改模型流程。

## 依赖与实现

- 已在主线：教学过滤、发布快照词义提取、来源复核、幂等单题任务、取消、草稿审核与反馈投递。
- 小改动：worker 排队有效期从首次提交起算；有界调度、公平轮转批次，重启后读取持久化队列。
- 新工作：独立分页接口、批次预览/创建/列表/详情/取消接口，批次表与任务关联、后台入口和严格契约。
- 关键路径：后端事务与迁移 → OpenAPI/wire/client → 后台 → 隔离真实联调。

## 行为与契约

每个当前发布教学释义（entry/publication/sense/definition 身份）× 学习等级 × 档位为一个覆盖单元；同一释义的多个基础词形在批次中去重。等级限制沿用现有候选规则；并非只按词义自身等级生成。有效 draft/approved 题目视为覆盖，活跃委托视为生成中，其余为缺题。来源或干扰项过期的题目不算覆盖。预览排除未发布、归档、非教学及无编辑权限词条。

旧 candidates、generation 与 Agent 响应不加字段。新增 candidate-page 返回完整分页。批次请求的等级/档位排序去重；预览 token 绑定实际缺题集合，创建时重新计算，变化则 409 要求重新预览；同键重试优先返回原批次。单题创建与批次创建共享事务锁，避免活跃任务重复。批次仅登记实际新建任务，初始覆盖/生成中统计保留。

队列最多并行两个 Agent 执行；先处理取消和已启动任务，再按批次最近派发时间轮转新任务，普通单题作为独立队列。任务执行前与结果导入时复核权限及来源。排队不消耗两小时有效期。取消只终止未完成任务，已生成草稿仍可审核。远端取消尚未确认且委托仍有效时继续占用执行槽，避免取消失败扩大实际并发。失败/候选不足保留明确状态，再次预览可重新补齐。批次状态和计数从持久化任务汇总，不依赖浏览器。

## 验收

- 超过 80 条、多词义及多等级/档位分页完整且稳定；排除非教学/无权限来源。
- 幂等、并发批次与单题创建不重复；来源/权限变化、取消、失败重试、重启恢复和长时间排队有实际测试。
- Rust DTO/OpenAPI、TS wire、严格 runtime validator 与后台匹配；旧响应兼容。
- 真实本地 PostgreSQL/Redis + 新后端 + Vite admin 验证预览、创建、刷新持久化、详情/取消和审核入口。模型沿用原真实证据，不额外付费；模拟 Agent 仅用于调度/结果边界测试，不作为模型联调证据。
- 迁移 up/down 在专属隔离库验证；清理本任务 fixture、数据库/Redis、进程及浏览器数据。回退前须停止批次入口和 worker，并排空或取消任务、确认远端取消；down 会拒绝活跃批次和未确认取消，再删除批次历史与关联，保留单题任务/草稿。
