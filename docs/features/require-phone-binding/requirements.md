# 手机号必绑与验证码登录

- C 端新邮箱注册用户及已有无手机号用户，必须验证并绑定手机号后才能访问业务页面/API。
- 手机号注册用户直接进入原有引导/业务流程；保留手机号或邮箱密码登录，新增手机号验证码登录入口。
- 未注册手机号不自动注册；邮箱注册继续要求密码和注册验证码。
- 绑定必须证明已有邮箱与新手机号的持有权；复用现有双验证码绑定接口。
- 补绑成功按现有安全策略使全部会话失效，整页回到登录并保留安全回跳；随后可用手机号验证码登录。
- 不允许解绑手机号；允许验证后换绑手机号、解绑邮箱。未补绑用户仍可退出或注销账号。
- 真实短信供应商接入、提交、PR、合并、部署不在本次实现范围内。Mock 验证不能代表短信已送达。

验收：邮箱注册/旧账号密码登录/恢复会话均进入绑定；不能通过直接访问业务接口绕过；补绑、换绑后旧 token 失效；手机号验证码登录及错误重试正常；手机已绑定账号原流程不回归。
