## 目标与范围

- 在每个新版义项下创建、编辑、引用已有例句和移除引用；例句是独立的新库资源，可被多个义项引用，不迁移或关联 V1 例句身份。
- 弹窗只编辑当前目标语言及媒介语言：en-GB/en-US 正文和配音分别保存，zh-Hans/zh-Hant 译文分别保存，切换视图不复制或覆盖另一语言。
- 复用现有富文本、CEFR 等级、三类译文风格、音色和音频上传控件。文字、参数修改和取消不正式生成，点击完成时补齐当前目标口音音频，再保存例句资源；义项引用应用到词条草稿，仍由词条保存动作持久化。
- 新库尚未开放发布、审核、AI 生成或已发布跨词读法引用，本轮不以 V1 接口冒充，不增加对应无后端能力的按钮。

## 数据与契约

- Rust `lexicon_next` 增加例句资源、永久子节点、义项引用和音频引用表。资源带 owner/revision；正文 variant 按 target locale，译文按 variant + medium locale。全部 wire 为 snake_case。
- `NextSense.sentence_ids` 为可选引用数组；明确空数组表示移除当前义项全部引用。资源独立存在，移除引用不删除资源。
- 资源 API：`GET/POST /admin/lexicon-next/sentences`、`GET/PUT /admin/lexicon-next/sentences/{id}`。创建使用客户端稳定 UUID，重试同一内容不重复创建；更新检查 expected_revision。
- 复用 sentences.access/create/edit 权限及其所有权范围；修改词条引用仍需对应 words.edit。引用仅允许同目标语的新库资源，拒绝 V1 ID、外部义项 ID、错误 locale、无效或被其他内容占用的资产。
- 通过 `x-tsz-next-sentences: v1` 协商能力、引用读写和预览字段。未声明的旧前端不收到新字段，保存时保留已有引用；新前端遇旧 API 关闭新能力。

## 可观察验收

- 英式创建并完成后，只生成英式音频；页面保存、刷新、预览显示相同正文、译文与引用。
- 切换美式补充正文/配音后，英式全部字段及资产保持不变；简繁译文同样隔离。
- 引用同一例句到两个义项，资源更新有共享范围提示；移除一个引用不影响另一个引用或资源。
- 编辑/取消零生成；生成或保存失败保留输入，重试不重复创建；并发修订冲突不覆盖其他语言修改。
- 权限、跨词条身份、无效资源、旧客户端保留及音频回收保护有针对性验证。
- 真实测试使用独占批次，先权限预检，结束彻底清理对象全部版本、登记、实体和引用并独立复查。
