# 新版 Step 3 多维例句

## 原型人工录入对齐与统一草稿（当前任务）

此前交付的是字段读写和基础预览，未完成原型的人工录入交互对齐。本轮明确补齐同卡片的原文、等级、语体/领域、来源及多条译文编辑，采用页面统一草稿保存，草稿预览包含未保存例句。AI 生成、审核、发布、独立句库生命周期及跨词关联不在本轮。

- 复用现有资源/富文本/语音/语言隔离；正文和译文直接输入，来源及高级标注/配音按需展开，不为排除的功能添加占位按钮。
- `x-tsz-next-sentence-drafts: v1`（同时声明既有 sentences/details 能力）协商 `sentence_drafts`。词条和已保存预览返回可选 `sentence_resources`，只向有例句查看权限的客户端提供；一次查询读取全部引用，避免每卡独立加载。旧客户端/旧服务组合保留基础编辑路径。
- 完整词条保存增加可选 `sentence_changes`，携带资源 ID、原 revision、目标变体和当前媒介语。词条、全部改动例句及引用在同一数据库事务中保存；同一资源可同时修改英美变体，只增加一次资源 revision，其他语言内容保留。任意权限、版本或输入失败整体回滚。新建使用客户端稳定 ID，重复提交不创建第二份资源。
- 数据库沿用已合入的表，无新增迁移。统一草稿只持有本地覆盖，不写进资源 Query 缓存；成功后采用服务器规范化资源并清空覆盖。切换英美保留各侧草稿，切换媒介语遵循现有词条归属与离开保护。
- 保存前校验全部字段，完全空白的译文占位不提交，文本存在而自由度为空允许保留。未评估不画已评分的 50% 滑块。文字修改复用 `editRichText` 重定位有效标注。
- 正式配音仅在明确保存后准备，覆盖所有改动过的英美变体，编辑/预览不生成。外部生成不属于数据库事务；保存失败保留输入及可复用资产，服务端最终校验 revision/归属/生成绑定。高级设置只是应用回本地草稿。
- 验收：截图布局和同卡片六条译文连续录入、自由度/空行/来源、未保存预览；统一保存刷新回读；某条冲突或无权时其他资源和词条均不改变；跨目标/媒介语保护、取消/离开、键盘和宽窄屏。使用独占本地数据库/Redis，无 mock 的真实页面；不把语音效果或真实 Azure/OSS 生成作为交付门。

## 人工录入与预览扩展（本轮）

- 基线：前端 `a6525aaa`、后端 `55579dc7`。基础功能已由前端 PR #811 / 后端 PR #422 合并发布，以下原交付记录保留作历史依据；本轮原先仅本地实施与验证；用户现已授权两仓提交、PR、CI 通过后合并并部署 tshb-test。交付基线已同步前端 `dac14554`、后端 `2f836b6`。
- 复用独立例句、语言范围保存、修订冲突及音频链路；新增原文变体的语体/领域与来源，译文的自由度与来源。来源有稳定 UUID，区分词典引用、网页引用、改写、AI 原创、人工原创；引用/改写必须有名称及网页或具体定位，外部来源只登记、不自动核验。
- `metadata` 为协商后的可选扩展。自由度为空/缺省表示未评估；已评估值为 0–100、最多一位小数，按 `[0,100/3]`、`(100/3,200/3]`、`(200/3,100]` 派生三类。保留旧 `style` 以兼容已有资源，不从分类伪造数值，不引入 `restoration`。非法自由度、空译文或非法来源在正式生成音频前阻断，输入保留。
- `x-tsz-next-sentence-details: v1` 声明能力，能力目录返回 `sentence_details`。旧客户端读取隐藏扩展，覆盖当前语言已有扩展时返回 422 并提示刷新；新客户端遇旧服务继续使用基础例句编辑。新服务拒绝隐式漏掉已有扩展字段，明确清空使用空数组/空值。原文扩展属于目标语言变体，译文扩展属于目标变体＋媒介语言。

- 译文默认从意译随机选择，同一资源修订、语言与阅读水平的选择在当前预览会话内保留。首次点击在 A1/A2 优先直译、B1–C2 优先创译，之后轮换未看过的译文；缺类明确回退。自由度滑块及键盘只选择已有译文，预览不生成或保存内容。

## 目标与范围

- 在每个新版义项下创建、编辑、引用已有例句和移除引用；例句是独立的新库资源，可被多个义项引用，不迁移或关联 V1 例句身份。
- 弹窗只编辑当前目标语言及媒介语言：en-GB/en-US 正文和配音分别保存，zh-Hans/zh-Hant 译文分别保存，切换视图不复制或覆盖另一语言。
- 复用现有富文本、CEFR 等级、三类译文风格、音色和音频上传控件。文字、参数修改和取消不正式生成，点击完成时补齐当前目标口音音频，再保存例句资源；义项引用应用到词条草稿，仍由词条保存动作持久化。
- 新库尚未开放发布、审核、AI 生成或已发布跨词读法引用，本轮不以 V1 接口冒充，不增加对应无后端能力的按钮。

## 数据与契约

- Rust `lexicon_next` 增加例句资源、永久子节点、义项引用和音频引用表。资源带 owner/revision；正文 variant 按 target locale，译文按 variant + medium locale。全部 wire 为 snake_case。
- `NextSense.sentence_ids` 为可选引用数组；明确空数组表示移除当前义项全部引用。资源独立存在，移除引用不删除资源。
- 资源 API：`GET/POST /admin/lexicon-next/sentences`、`GET/PUT /admin/lexicon-next/sentences/{id}`。创建使用客户端稳定 UUID，重试同一内容不重复创建；更新检查 expected_revision。
- 复用 sentences.access/create/edit 权限及其所有权范围；修改词条引用仍需对应 words.edit。引用仅允许同目标语的新库资源，拒绝 V1 ID、外部义项 ID、错误 locale、无效或被其他内容占用的资产。
- 通过 `x-tsz-next-sentences: v1` 协商能力、引用读写和预览字段。未声明的旧前端不收到新字段，保存时保留已有引用；新前端遇旧 API 关闭新能力。

## 可观察验收

- 英式创建并完成后，只生成英式音频；页面保存、刷新、预览显示相同正文、译文与引用。
- 切换美式补充正文/配音后，英式全部字段及资产保持不变；简繁译文同样隔离。
- 引用同一例句到两个义项，资源更新有共享范围提示；移除一个引用不影响另一个引用或资源。
- 编辑/取消零生成；生成或保存失败保留输入，重试不重复创建；并发修订冲突不覆盖其他语言修改。

- 真实测试使用独占批次，先权限预检，结束彻底清理对象全部版本、登记、实体和引用并独立复查。
