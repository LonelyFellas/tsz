# 学生创编拼写任务：需求

日期：2026-10-18。阶段：已完成本地实施与验收。日期估算、续轮、来源阻塞和兼容规则已按修订方案实现。

用户已确认：仅做看中文释义、拼写英文；采用按轮覆盖、最后一天做剩余题量、日期计划可选。实施阶段已完成。2026-10-18 用户进一步授权按 ship 审查、修复、提交、推送并分别开 PR；不合并或部署。

配套 [技术方案](design.md)。本目录是本次跨仓任务的唯一主记录。旧学习系统的历史基线见 [学习任务基础需求](../coins-system/learning-task-foundation-requirements.md)；本方案不改写旧任务和既有完成记录的含义。

## 1. 目标与边界

学生可以选择词表、确认可出题数量，创建每日任务或长期任务。每日任务按计划覆盖一轮全部内容，跨天不重复已有效作答的学习单元；最后一个学习日只做剩余题量。长期任务不拆每日额度，一轮覆盖全部内容。

本次包含创编、列表/学习首页摘要、详情、练习与整体覆盖进度之间必要的衔接。复用既有鉴权、中文拼写出题、首答判分、答题历史与奖励结算，不重建学习系统。

不包含教师布置、班级、其他题型、自定义词汇出题、错题复习算法、正确率门槛、通知提醒、自动续轮、任务参数编辑或奖励规则调整。

四张原型用于确认字段、交互与信息层级；批注不是额外执行指令。视觉遵循 [Web 风格规范](../../../apps/web/style.md)。

## 3. 三个层级

| 概念     | 含义                                               | 例子                         |
| -------- | -------------------------------------------------- | ---------------------------- |
| 任务     | 名称、来源词表、类型、每日题量与可选日期计划       | 每日 100 题的七年级词汇任务  |
| 覆盖轮次 | 本轮固定的全部学习单元及累计覆盖进度               | 第 1 轮，共 235 题           |
| 练习批次 | 复用现有 run；每日为当天分配的题目，长期为整轮题目 | 每日三批分别 100、100、35 题 |

每日页面使用“今日已答”和“本轮已覆盖”区分两种进度；长期页面只有整轮进度，避免显示两个相同的进度条。旧任务仍按原有 run 展示，不伪装为新覆盖轮次。

## 4. 创编流程与字段

流程：填写名称 → 选择任务类型 → 选择词表 → 自动计算题量 → 设置每日题量及可选日期计划 → 完成创建。

| 字段/区域 | 规则                                                                                                   |
| --------- | ------------------------------------------------------------------------------------------------------ |
| 任务名称  | 必填；去除首尾空白后 1–50 个 Unicode 码点；显示字数。旧任务原有最长 100 字名称正常展示，不静默截断     |
| 任务类型  | 默认每日任务；可选长期任务。切换保留名称、词表；每日专有输入可在当前草稿保留，但长期提交不得携带这些值 |
| 选择词表  | 支持我创建的、我收藏的目录及公开词表搜索；词表 ID 去重，确认后最多 5 份                                |
| 已选词表  | 展示原名、必要的个人备注名、作者、公开状态及词条数；名称最多两行。可单独移除，不修改词表或收藏         |
| 题型      | 固定显示“拼写题 · 看中文，写英文”，不提供唯一题型的复选框，不展示其他题型的零值占位                    |
| 题量摘要  | 显示词条数、可出题数及必要的排除说明；以服务端结果为准                                                 |
| 每日题量  | 每日任务必填整数 1–200；默认 10。可以大于本轮题数，此时一天做完；不足一天的题量不强行凑题              |
| 预计天数  | 每日显示“按每天完成计划量，预计 X 个学习日完成本轮”；不是保证在 X 个自然日内学完                       |
| 日期计划  | 每日默认关闭，创建后可立即学习、无结束日期。打开后开始、结束日期均必填                                 |
| 长期任务  | 不设置每日题量、预计天数和日期计划；完整覆盖一轮，可跨天继续                                           |
| 完成创建  | 提交期间防重复操作；成功进入任务详情，展示首轮题数与开始入口；失败保留草稿                             |

完成创建使用一个页面级主按钮，长页面滚动时保持可达，小屏不遮挡最后一个字段及错误提示。不另加无信息增量的确认弹窗。

### 4.1 词表与文件夹选择

- 选择器维护临时选择；“确认选择”更新表单，“取消”丢弃本次弹窗内变更。
- 支持搜索、分页、目录导航与跨页保留选择；词表选择卡片不承担点赞、收藏或跳转阅读操作。
- 选择文件夹表示包含确认时文件夹及全部子文件夹中的词表。服务端统一展开、按词表 ID 去重，再显示待确认列表。
- 同时选择祖先、子文件夹和同一词表只计一次；超过 5 份、空文件夹或含不可用来源时明确提示，不静默截断或漏选。用户可以改为逐份选择可用词表。
- 选择结果保存具体词表 ID。之后移动目录、新增子词表、取消收藏，不自动增减任务来源；来源内容权限仍按既有规则判断。
- 收藏他人词表不授予私密内容访问权；来源不可访问时不泄漏原作者内容。

### 4.2 自动题量与内容资格

- 词表、任务类型、每日题量、日期或学习设置变化后自动重新预览；请求中显示计算状态，迟到响应不能覆盖新选择。
- 同一学习单元按 `(entry_id, pos_id, sense_id)` 去重，不按词面合并不同词条或义项。
- 复用现有 CEFR 释义选择、英美偏好及合法原形答案规则；无适配中文释义、依赖上下文、无合法原形、题面泄漏答案等内容排除。
- 沿用 [自定义词汇约定](../wordlist-custom-vocabulary/design.md)：混合词表仅平台项参与；纯自定义词表可被浏览，但可出题数为零，不能创建本轮。界面明确提示自定义词暂不参与出题。
- 沿用最多 1000 个去重平台词条、最多 2000 个候选学习单元的保护上限；超限提示拆分任务，不部分计入。
- 可出题数为零不能创建。预览与创建间来源或设置变化时，保留输入并要求用户核对更新后的题量，再次提交；不得静默创建不同内容。

## 5. 按轮覆盖与每日分配

设本轮总题数为 `T`，累计有效首答覆盖数为 `C`，每日题量为 `N`，剩余 `R = T - C`。

- 没有来源阻塞时，首次预计天数为 `ceil(T / N)`。后续估算必须考虑今日实际剩余可答数量，具体见下方公式；不能把 `ceil(R / N)` 直接用于当天部分作答后的估计。
- 没有来源阻塞时，每个新学习日分配 `min(N, R)` 道尚未有效作答的题目。已有效作答题目不在同一轮再次分配，答错也算覆盖；正确率单独统计。
- 同日未完成恢复原批次，同日已完成查看结果，不额外发放第二批。最后一个学习日的题量可以小于 N。
- 跨日未完成批次按原规则过期，其已保存的有效首答继续计入本轮覆盖；未答题回到本轮待分配集合。不会把整批标成完成，也不抹掉已答内容。
- 漏掉整天不会推进覆盖，不自动增加次日题量，不补过去日期的完成或奖励；预计完成时间相应后移。
- 覆盖数等于总题数时整轮完成。当天批次完成不等于整轮完成。
- 本轮完成后不自动抽新题。用户可主动开启下一轮，重新读取当前可用词表内容与设置。每日最早从**上一轮完成日的下一学习日**开始：昨天完成、今天点击续轮，可以今天学习；今天完成、今天点击则明天开始。长期可以立即续轮。
- 续轮或明确放弃受阻轮后重建，网络结果未知时重试同一请求，应返回已创建的同一轮，不得因为前驱已变化而要求再次创建。

**剩余学习日的计算：** 没有待答来源阻塞且 `R > 0` 时，设今日还能合法作答的数量为 `A`。今日已有未完成批次，`A` 等于该批次未答数；今日尚未开批且允许开始，`A = min(N, R)`；今日已完成、尚未到计划开始日或当前不能开批，`A = 0`。

- `A > 0`：包含今天还需 `1 + ceil(max(R - A, 0) / N)` 个学习日。
- `A = 0`：从下一个允许学习日算起还需 `ceil(R / N)` 个学习日，界面同时说明起算日，不把今天重复计为可用日。
- `R = 0`：本轮已完成，剩余天数为 0。计划已结束时不展示未来可完成承诺。
- 存在不可用待答题时显示“有 B 题待恢复，暂无法预计整轮完成时间”，不输出误导性的有限天数。

| 场景                                    | 预期                                                  |
| --------------------------------------- | ----------------------------------------------------- |
| 235 题，每日 100，按计划完成            | 三个学习日分别 100、100、35；本轮覆盖 235，无跨批重复 |
| 235 题，每日 100，首日只做 60           | 首日批次过期，覆盖保留 60；后两天分别分配 100、75     |
| 235 题，每日 100，首日已答 60、尚未跨日 | 今天还可做 40，其后 100、35；包含今天仍需 3 个学习日  |
| 昨天完成一轮，今天点击续轮              | 今天可开始，不从点击之日再顺延一天                    |
| 35 题，每日 100                         | 首日只分配 35，完成即整轮完成                         |
| 某天完全未开始                          | 不创建虚假的完成；下次仍从未覆盖内容继续              |
| 全部答错，但每题均有效作答              | 正常完成，正确率为 0%                                 |

### 5.1 内容变化与来源失效

- 首轮在创建事务中固定候选集合、顺序、中文题面、允许答案及学习设置；普通发布、追加词条或修改学习设置不改变本轮。下一轮才采用最新内容。
- 固定快照不绕过实时权限。来源撤回、移除、归档、删除等仍复用现有可用性规则及删除宽限边界；没有资格继续使用的待答内容不能通过旧快照读取。
- 不能自动删掉不可用题、降低总数并宣布学完。待答题不可用时，标记为“来源不可用”，隐藏其内容，保留本轮已覆盖数及原总数，允许继续其他合法内容。本轮显示已覆盖、仍可答、不可用三项数量；“不可用”属于未覆盖部分。
- 当前批次中途出现不可用待答题，不改该批次目标数、不追加替代题。其他题可继续；未全部有效作答就不生成该批次完成或奖励。每日到点后该批次过期，合法首答仍计入覆盖。
- 后续每日新批次从可用且未覆盖的单元中取 `min(N, 可用未覆盖数)`。因来源阻塞而不足 N 时明确标注原因，不能标成“最后一天”；该批次全部有效作答可按真实题量完成，但本轮仍须覆盖原来的全部 T 题。长期批次始终包含整轮固定单元，可答合法部分，不可用项保留为未答，不缩小目标数。
- 没有合法待答内容时暂停开始入口，保留进度并提供“检查来源”。刷新只重新核实既有来源身份/代次和权限，不借恢复按钮把已撤回、移除后重建的来源当作原来源，也不复活已失效的旧批次；仍无法使用时继续显示不可用。
- 不自动重新生成整轮。用户可明确选择“放弃本轮并重新生成”，先展示旧进度、仍不可用数、新候选题数和新进度从零开始的影响，再确认；成功后旧轮记为取消并保留历史，不冒充已完成。现有任务来源仍不可访问、无候选或日期容量不足时拒绝重建，保留旧轮，允许用户新建其他来源的任务。
- 每日重建时，若本任务今天已有任一合法首答或有效完成，最早次日开始；若今天从未合法作答、也无完成，可取消旧空批次后当天开始。检查范围覆盖本任务全部轮次，不能反复重建刷新日额度。长期可以立即重建。
- 已覆盖内容后来失去权限时，覆盖统计不倒扣，对应题面和答案按现有规则隐藏；不单因此使剩余合法内容无法继续。
- 删除宽限只保护符合现有规则的已开始批次，不延伸到未来批次。若按既有删除规则，宽限内完成当前批次后必须归档任务，则同一操作停止剩余轮次；未全部覆盖的轮次保留为取消及原覆盖数，不能显示整轮完成。此规则优先于普通的来源阻塞继续策略。

## 6. 可选日期计划

- 时区固定 `Asia/Shanghai`。学习日 D 为 `[D 04:00, D+1 04:00)`，由服务端时间判断；凌晨 04:00 前“当前学习日”仍是前一日，界面须有说明。
- 不开启计划：保存后立即可学，未完成内容可在后续学习日继续，没有时间截止；“立即开始”不表示自动开始答题。
- 开启计划：开始日不得早于当前学习日，结束日不得早于开始日；包含首尾两日，可用学习日数为 `结束日 - 开始日 + 1`。
- 可用学习日数必须 **大于或等于** `ceil(T / N)`，恰好足够应允许创建；长期任务不得携带日期计划。
- 生效区间为 `[开始日 04:00, 结束日次日 04:00)`；当前已处于开始日窗口时，保存后即可学习，不要求补足已经过去的小时。
- 开始前显示“尚未开始”及开始日期，服务端拒绝提前开批和作答；到达结束边界后拒绝新批次和未完成批次的新作答。
- 计划结束而本轮未完成，显示“计划已结束，已覆盖 C/T”；不伪造完成，不静默延长计划，不自动追加题量。
- 运行中判断能否按期完成时，容量为“今日实际剩余可答数 A + 结束日前其余允许学习日数 × N”，不能简单用包含今天的天数乘 N。容量小于 R 时提示可能无法按期完成，保留仍可进行的练习；有不可用待答题时另显示来源阻塞，不能保证完成日期。
- 在同一任务内再开一轮必须仍有足够剩余学习日；按上轮实际完成日、当前学习日、计划开始日及重建的当天作答限制确定最早学习日，不以点击按钮的日期机械顺延。日期不够时提示新建任务，本期不提供延长/修改计划。

## 7. 完成、奖励及历史兼容

- 复用服务端首答和完成事实，不引入正确率或学习时长门槛。每个任务每个学习日最多一个有效每日完成事实。
- 整体覆盖按所有合法首答累计；每日奖励仍只统计 **当日已完成每日批次** 的去重单元，部分完成/过期批次不计奖。两种进度不混用。
- 沿用已确认的学习奖励政策：10 个去重单元达标、每日 5 币，实际是否启用及金额以服务端当天政策为准；长期不参与。本次不改奖励配置。
- 最后一天只有 5 题时，做完即完成本轮；如果当天其他任务未凑足奖励门槛，可以没有学习奖励。不能为奖励凑题、重复题或提高最后一天题量。
- 旧每日任务继续原有每日抽题行为，旧长期任务和历史记录保持原义；不根据旧题目反推一轮覆盖，也不把旧完成重算为新奖励。
- 新版页面可查看旧任务并明确原有模式；旧客户端不应把新计划解释为旧抽题任务。若旧列表不能完整展示用户的新任务，应明确提示“任务功能已更新，请刷新页面后继续”，不得静默隐藏后显示空列表或不完整列表。刷新后的新版页面应重新读取完整任务；提示不能丢弃未提交的答题输入。兼容协议见技术方案。
- 学习参数创建后固定。本期仍只支持重命名和归档；归档停止新批次并取消未完成批次，历史与奖励事实保留。

## 8. 验收标准

| 风险/用户路径        | 可观察结果                                                                                                           |
| -------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 创建与持久化         | 每日/长期均可创建，重新请求及整页刷新后名称、词表、计划和首轮题数一致                                                |
| 覆盖与尾量           | 235/100 得到 100、100、35；35/100 得到 35；没有已答单元跨日重复                                                      |
| 部分、漏学、错误答案 | 60 题保留覆盖，未答重新分配；漏天不推进；合法全错可完成                                                              |
