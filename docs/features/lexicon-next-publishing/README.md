# 新版词库发布闭环

目标：新版新建/保存内容可在预览页检查并明确发布，列表及重开显示真实发布状态，可独立读取不可变发布版本。V1 与既有消费者继续使用原接口。

基线：前端 `63d210637156ebf299b415b218ca28269da837a0`；后端 `b195f3b83a5b32ddfaa3b2d20f3d481115e95b4b`。两仓分支 `codex/lexicon-next-publishing`，后端任务工作树 `lexicon-next-publishing-api/tsz-rust`；本文件是唯一主记录。

## 剩余依赖与范围

- 已有：完整草稿、语言归属、词性发音/释义/例句、资源归属、列表权限与并发锁。
- 可复用：共享预览控件、`words.publish` 所有权规则（本人或超管）、会话及授权事务锁、音频资产锁/回收保护。
- 新增：独立不可变发布快照、预检/发布/当前版本读取、前端确认与相同请求重试、发布状态和列表筛选。
- 范围：本轮单条发布；批量发布入口明确提示逐条发布。关联例句版本随词条冻结；不将新库数据写入 V1，不切换现有 Web/命题题源，不自动审核或授予测评资格。完整独立例句生命周期、历史回退及消费者迁移不在本轮范围。
- 用户确认：无音频允许文本发布，显示音频缺口；不自动赋予听辨、跟读或测评资格。

## 契约与保护

`POST /admin/lexicon-next/entries/{id}/publication-preview` 读取已保存的精确草稿和 lifecycle 版本，返回阻塞项/提醒及绑定内容与依赖版本的 token。`POST .../publications` 只接收版本/token/请求 ID，服务端重新检查权限、归属、状态、完整性、例句及关联目标、音频就绪/引用，原子生成快照和回执。相同请求只生成一次版本；未知结果沿原 ID 重试。`GET .../publication` 独立读取状态与快照，不用本地预览冒充发布内容。

草稿后续编辑不改发布快照。关联例句冻结文档和 revision，音频与语体/行业目录保留独立发布引用，避免草稿删除音频后被回收，或共享例句移除目录配置后破坏历史。关联目标必须有当前可用发布版本且包含对应义项；待关联文本可显示为文本并提醒。归档遮蔽发布内容，恢复保留原发布；有发布历史禁止永久删除。

旧客户端不带新版发布协商头时管理响应将 published 映射成 draft，保持严格 enum 兼容；服务端仍按真实状态与发布历史实施保护。新客户端连接旧服务时 publishing=false 禁用入口，不回退 V1。新增迁移 up/down 成对；存在发布数据时 down 拒绝丢弃。配套上线先后端后 Admin，旧后端不能识别发布状态，发布数据产生后不得直接回退旧二进制。

## 可观察验收

1. 创建、保存有效草稿，预检、确认发布；独立 GET/列表/重开均显示相同发布身份及内容。
2. 保存不完整草稿仍可行，发布阻塞项明确且不写入快照；无权限/归档/过期版本/依赖变更不发布。
3. 相同请求重放和并发不重复发布；网络未知结果保留 ID；发布失败保留草稿。
4. 已发布后再改草稿及共享例句，读取旧发布版本内容不变；资产引用仍受保护。
5. 后端真实隔离 PostgreSQL、定向事务/权限/迁移测试，前端契约/交互测试；真实页面通过同源代理连接任务后端，关闭业务 mock，完成创建→保存→发布→重开。
