# 释义与例句编辑器格式

英文释义语句与共享例句沿用 association 编辑器，增加普通黑色加粗、斜体和实线下划线，并开放逐个清除连读与停顿。截图蓝底按临时选区反馈理解，不新增持久底色。格式按钮只作用于选区，不增加后续输入继承格式。

## 验收

- 三种格式可叠加；完整覆盖时再次点击取消，混合选区点击补齐，局部取消保留两侧；点击按钮后选区保持。
- 连读起点、终点、一次添加及停顿沿用现有行为；清除模式仅删除点击的连读或停顿，保留格式、正文和关联，并可撤销。
- 编辑、完成收起、保存重开和阅读展示一致；取消恢复本次编辑前的正文、标注、音色及关联。
- 文本修改按 Unicode 码点重定位格式，保留未修改片段；英美方言及释义/共享例句关联数据保持隔离。
- 只读禁止写入；关联能力关闭仍保留既有数据；不扩大音频上传权限。
- 视觉格式不改变 SSML，停顿继续影响语音；保持现有完整内容缓存指纹规则。

## 验证命令

- `pnpm --filter @tsz/voice-editor test`：格式切换、归一化、改字重定位、清除和阅读渲染通过。
- `pnpm --filter @tsz/api-client test`：OpenAPI 与严格运行时枚举同步，未知注解仍被拒绝。
- admin 受影响组件/例句测试：完成取消、保存往返、方言和关联隔离通过。
- `pnpm typecheck && pnpm lint && pnpm test`：最终跨包质量门通过。
- 后端 `SQLX_OFFLINE=true cargo test --locked --all-features --lib` 与 clippy、fmt：两套 DTO、格式归一化、SSML 及序列化通过。
- 真实浏览器：选中词组后连续设置 B/I/U，插入停顿、添加连读、完成重开；字形、选区及弧线锚点不偏移，正文不包含停顿标签。
