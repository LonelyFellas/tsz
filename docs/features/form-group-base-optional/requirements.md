# form-group-base-optional：词形变化组原形默认项放宽

## 用户与目标

- 词典 admin 词条编辑 V3（word-creation-v3）里，一个词性（POS）下可建多个「词形变化组」（form group）。
- 现状：每组都必须有至少一个「原形」（base）词形——新增组自动塞原形，且每组唯一原形不可删、不可改类型。
- 目标：**只有第 1 组必须有原形**。第 2 组起不再自动带原形，唯一原形可删、可改类型。
- 目标端：前端 tsz（admin）+ 后端 tsz-rust。

## 主流程

1. 新建词条 POS 时，第 1 个词形变化组自动带一个原形（沿用现状）。
2. 之后每新增一个词形变化组（第 2、3…组），组内**不自动塞原形**，由用户手动加词形（通常是屈折形）。
3. 第 2 组起若只有唯一一个原形，该原形可删除、可改类型（不再锁）。
4. 发布校验：只有第 1 组必须有 ≥1 个原形；第 2 组起可无原形，但组仍不能为空。

## 关键异常 / 已知代价（已确认接受）

- 第 2 组起若同组无原形，该组的屈折形在「关联候选 / 短语成分」里 `base_form_ids` 为空，不再出现为可选目标（后端 `sentence_association.rs:405` 计算、`:539` 展开）。这是本次放宽的既定代价。

## 范围（不做）

- 空组规则不变：发布时任何组都不能是空组（`EmptyFormGroup`）。
- 第 1 组必须有原形不变。
- 不涉及词义绑定、发布快照结构、OpenAPI 字段增删（无 DTO 变更）。

## 验收标准

- [ ] 前端：新增第 1 个变化组自动带原形；新增第 2 个及以后组内无原形。
- [ ] 前端：第 1 组唯一原形仍锁删 + 锁改类型；第 2 组起唯一原形可删、可改类型。
- [ ] 后端：complete 发布时仅第 1 组缺原形报 `BaseFormRequiredInGroup`；第 2 组缺原形不报。
- [ ] 后端：第 2 组无原形时屈折形关联候选 `base_form_ids` 为空（不 panic，返回空候选）。
- [ ] 后端：空组仍报 `EmptyFormGroup`；第 1 组缺原形仍报错。
