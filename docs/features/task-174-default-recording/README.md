# 禅道任务 174：上传录音的默认播放

任务：[上传音频，无法设为默认播放音频](http://47.121.142.19/zentao/index.php?m=task&f=view&taskID=174)。

## 范围与根因

修复前，上传列表只有试听和移除；正式播放和发布检查优先采用已选合成音频，没有上传录音的默认选择。新增选择还必须经过服务端元数据回填，否则保存后会被清除。

复用现有上传、资产权限、草稿保存和播放链路。新增可选 `AudioAsset.is_default`，表示当前正文对这条录音的选择；英式、美式分别至多一条，缺省保持原来的播放规则。选择随录音引用保存，仍须保存正文草稿；移除录音同时移除选择。Azure 配音参数和生成音频绑定不被替换。

配音详情、词形总览和审阅页读取默认选择；后端的字典音频顺序与发布检查采用相同优先级。服务端回填真实录音元数据并保留选择，按真实口音拒绝重复默认录音。无需数据库迁移。
