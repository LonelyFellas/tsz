## 契约与兼容

`NextDraft.sense_groups` 是可选、非 null 的数组，每项保存 `id/name_zh/name_en`；`NextSense.sense_group_id` 是可选、非 null 的稳定 ID。沿用现有不可变草稿快照，节点身份登记增加 `sense_group` 类型，不读取或复制 V1 业务数据。草稿允许未填区间名称，名称上限 200 字符。

客户端以 `X-TSZ-Next-Sense-Groups: v1` 协商能力及响应。未协商的旧客户端读取时不收到新字段；已启用区间的草稿拒绝省略整个区间字段的旧保存请求，避免静默覆盖。新前端访问旧 API 不显示区间编辑能力，也不发送新字段。

新增迁移 `20261113140000` 扩展节点类型约束。down 在存在区间节点或扩展快照时拒绝执行，不删除业务内容。已有区间快照后不可回退到旧后端二进制；需先停止新写入并采用经过验证的恢复方案。发布顺序为兼容后端 → 新前端，旧前端过渡期间没有区间写入口。
