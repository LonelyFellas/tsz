# 语法结构编辑器实现

## 复用与新增

词形关联、三类语法标注、连读端点、停顿时长、声音选择复用现有实现。调整语法模式的工具布局和选区说明，新增持续清除模式及非线性宽度行内停顿标签。

停顿标签占据词间的真实宽度。有停顿时，鼠标在显示层原生选字，排除标签文字后映射回原生文本框；键盘输入和剪贴板继续处理原文，显示层按码点回显选区和光标。没有停顿时沿用原有叠层输入行为。

斜体新增 wire 注解 `{ type: "italic", start, end }`，偏移为 Unicode 码点。前后端归一化合并同类相邻或重叠区间，保持既有非空、越界、跨段及总量约束；斜体可与其他注解交叉。

编辑器将斜体保存在其他区间注解中，独立切分取消选区，并随正文编辑保留未改动片段。显示层使用隐藏的普通粗体字形占位，只将可见字形设为斜体，保持原生文本框的光标和字宽一致。阅读视图以 `i` 渲染。

## 语音与持久化

TTS 不为斜体或加粗生成 SSML 标签，不改变正文、音素、停顿或语速。保留既有完整内容缓存指纹规则。

后端核心与 V3 DTO 同步增加注解，通过现有 JSONB 和发布快照保存，无需数据库迁移。OpenAPI 由后端导出，前端端点快照和严格 runtime bundle 由原生同步脚本生成，不放宽校验。

## 兼容与验证

新版本可读旧标注；旧前端严格校验及旧后端枚举均不接受斜体。配套发布必须在相关读写消费者全部升级后启用新格式写入；存在斜体数据时不能直接回退旧后端。

验证覆盖选区设置、部分取消、撤销/重做、Unicode 范围与文本重定位、格式共存、真实草稿保存读回和 SSML 等值。独立本地验收词条与用户编辑中的草稿分离。
