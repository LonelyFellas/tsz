# 语法结构编辑器与视觉格式

语法结构编辑器按提供的原型保留顶部文本编辑、斜体、词形关联，以及字母级三类语法标注和连读操作。取消、完成位于正文区底部，停顿和声音工具位于其后。

- 选区可同时用于语法分类与连读，显示选中的文字和可用操作。
- 三类语法标注仅保留选区设置类别，不提供“移除选区标注”和“连续标注”。
- 连读起点、终点和一次性添加使用对应的半弧、半弧和完整弧线图标；不提供自定义颜色，连读线继承正文默认字色。
- 关联以完整单词定位具体词形，复用已有词形与地区变体身份。
- 斜体对选中文字设置或取消，允许局部取消，支持撤销、重做及保存后重开。
- 斜体与加粗仅影响视觉；相同正文、音素和停顿下，SSML 必须完全一致。
- 清除模式持续开启，点击已有连读或停顿逐个取消，不移除文字、斜体、语法分类或词形关联。
- 停顿使用紧凑蓝色秒数标签，直接占据两词之间的行内位置，宽度随时长先快后慢增长；标签不进入正文、选区码点或剪贴板文本。
- 选中“停顿”即显示全部空词缝的灰色插入位，并立即启用预设秒数与自定义时长；可以先选时长再点词缝，也可先选位置再选时长。取消选中后隐藏插入位并禁用时长操作。
- 添加停顿成功后保持模式选中，后续点击词缝沿用刚选的时长；再次点击“停顿”、切换工具或按 Esc 才退出。
- “移除停顿”排在时长与“应用”同行；不提供额外的连续添加按钮和时长范围提示。
- 顶部关联按钮显示“关联单词”，“上传音频”位于“发音”右侧、音色清单上方。
- 音色清单默认展开，点击“发音”收起或展开，箭头同步变化；收起保留音色和语速配置，不隐藏上传音频入口。
- 弹窗内容有未完成的修改时，Esc 不直接关闭；仍可退出操作模式，撤销回原内容后可正常关闭。

验收包括组件操作、严格运行时契约、后端保存与独立读回、真实浏览器刷新重开，以及带音素和停顿的 SSML 等值验证。
