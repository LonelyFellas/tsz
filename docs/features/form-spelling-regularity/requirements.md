# 词形拼写的规则变化标记（TASK 53）

将规则变化标记从变化组移到每个词形的拼写。英美拼写区分时各自设置；拼写统一时仅一份，即使发音仍分英美。这里只录入、持久化和回显，暂不增加业务消费者。

验收：

- 删除组级开关；对应拼写右侧显示是/否，原形和派生词形均可设置。
- 单个拼写的修改不影响同组其他词形或另一方言。
- 拼写统一、发音区分时一个开关同步保存两个底层变体。
- 保存/读取、发布快照、词形复制和英美结构转换保留值。
- 拆分继承；合并遇到不同值须先统一，不默默丢值。
- 历史缺字段沿用旧组值，已有新值优先；旧请求不覆盖已存的新值。
- 保留同一前端 worktree 中删除蓝色“英美通用”标签的改动。
