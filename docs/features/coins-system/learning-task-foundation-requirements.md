# 真实学习任务基础：需求与完成规则

日期：2026-10-07。阶段：LT-01～LT-04 已实现并完成隔离验收；本轮交付目标为两仓任务分支 PR，尚未合并或部署。需求与设计集中维护在本目录；配套 [技术设计](learning-task-foundation-design.md)，实施批次见 [tasks.md](tasks.md)。

## 1. 已确认范围与依据

用户本轮确认：

1. 首批做**学生自建每日任务和长期任务**，暂不接教师布置、班级或师生关系。
2. 首批题型是**看中文释义拼写英文**，不同时接单选、听写、跟读或自由翻译。
3. **规定题量全部有效作答即完成，正确率独立统计**。答错不阻止完成；不擅自增加全部答对、最低正确率或最低时长门槛。

本阶段交付可信学习事实，**不发天生币**。COIN-12 的计奖单位、金额、上限、重复学习是否计奖仍未确定。完成记录不是领取成功凭证，页面不出现可领取按钮或伪造 coins_earned。

产品文档来源为本地总文档仓库 `/Users/darwish/Dev/tsz-core/.worktrees/shared/docs-consolidation/product.md` 的模块 6/7：每日与长期任务、按词表自动出题、记录可回看；每日进度于北京时间 04:00 刷新。这是本批日界线的已有依据，不能把“Asia/Shanghai”自动解释为 00:00。

用户随后确认：每日采用 **04:00 换日＋整个任务结束时刻**，不另加每天固定截止点；长期任务**按轮次学习**，每轮覆盖开始时全部可出题内容，完成后可主动再开一轮。

## 3. 任务、轮次与题型是三个概念

| 概念     | 每日任务                                       | 长期任务                                   |
| -------- | ---------------------------------------------- | ------------------------------------------ |
| 任务定义 | 名称、词表集合、每日题量、可选整个任务结束时刻 | 名称、词表集合；不配置每日题量             |
| 本次练习 | 一个服务端业务日的一轮固定题目                 | 一轮固定可出题内容集合                     |
| 规定题量 | 用户设置 N，开始时必须有至少 N 个去重学习单元  | 开轮时可出题学习单元的实际总数，必须大于 0 |
| 完成     | N 道均有首次有效作答                           | 本轮每道均有首次有效作答                   |
| 再次开始 | 同日未完成恢复原轮；完成后返回原结果，不重置   | 未完成恢复原轮；完成后由用户明确开启下一轮 |
| 内容更新 | 下一业务日/合法重开时读取最新来源              | 下一轮读取最新来源；已开始轮次不被改写     |

题型固定为 `spelling_zh_to_en`，不是把“每日/长期”当两种答题方式。师生共用账号时，本批只按真实 student 资格和学生学习设置创建自己的任务；教师阅读时的 C2 预览不进入判题。

## 4. 首批出题与判定建议

以下规则已按本批最小范围实现，不代表完整自动题库：

- 来源只允许**本人词表**及**当前可访问的公开词表**；不引用其他人的私密/待审内容，不接受任意 publication_id。
- 学习单元按 `(entry_id, pos_id, sense_id)` 去重，多个词表引用同一单元不重复凑题。词表数量、词条数量和题目数量分别显示。
- 每义项沿用现有阅读等级优先级：先当前/最近较低 CEFR，同级中文优先，顺序稳定；若选中的内容无法形成中文拼写题则排除，不为出题偷偷抬高等级、跳到更低中文或调用翻译补题。
- 首批仅使用可独立理解的 `zh_definition`；依赖上下文、仅英文或句子表达、空内容、缺失关联原形的义项明确列为暂不可出题。语法填空/衍生词形另批，不能用整词拼写冒充它们。
- 标准答案来自与义项实际关联的 `base` 词形，复用 general/dedicated 关系；common 或用户英/美偏好的真实拼写进入允许答案集。多个合法原形可有多个允许答案，不臆造同义词或另一地区拼写。
- 题面给出中文定义及必要词性；不提前返回答案、正确标记、音标或英文词面。题面若按独立拉丁词/完整短语边界直接包含允许答案则排除，避免明显自泄题；这不保证用户无法从公开词表找答案。
- 建议判定复用 `normalize_headword` 的规范化规则：NFKC、首尾/连续空白、大小写、常见撇号/连接号写法归一；除此之外精确匹配，不用编辑距离或 LLM 宽松判分。保留 `grading_version`，不能升级算法后改写已判结果。
- 有效提交是：题目属于本人当前轮次、题目未首次作答、答案非空白且长度/字符格式合法，并通过时间和内容权限检查。空白、超长、伪造归属等不占首次作答；有效但错误的拼写计入完成数量，correct=false。
- 每题只保存首次有效作答。结果响应可展示该题正确拼写和反馈；后续修改输入不覆盖首答或准确率。不新增“点击完成”、已读停留时长或客户端 completed=true 的旁路。

每日不足 N 题时明确显示可出题数与排除原因并阻止开轮；不静默降题量、不重复同题补足、不把不可用项算完成。长期候选为空也拒绝开轮。预览不预留内容，正式开始必须重新核实。

首批任务学习参数创建后固定；只支持重命名与归档。后台词库发布/词表内容更新仍会影响新轮次。需要不同题量/词表组合时新建任务；不做生效版本排期或中途改题。此取舍用于控制首批范围，实施前可调整。

## 5. 时间、恢复与来源失效建议

- 每日窗口采用 Asia/Shanghai 的 `[当日04:00, 次日04:00)`；服务端派生 business_day。例如 10 月 8 日 03:59 仍属 10 月 7 日，04:00 才属 10 月 8 日。
- 每日轮次的有效截止为业务日窗口末尾与整个任务 ends_at 的较早者。跨日未完成轮次转为过期，不能挪到次日补打卡；已提交成功的请求可以原键重放，但不能因此新建次日轮次。结束时刻按半开边界判断。
- 过期仅禁止继续作答；已答内容在当前仍有来源权限时保留复盘，未答题不开放答案。长期轮次不因换日过期。页面刷新、断网、换设备都恢复服务端已记录进度，不能靠 localStorage 保住唯一事实。
- 学习设置与题面/答案在开轮时固定；后续英美偏好或正常新发布不改正在作答的标准答案。词表仅重命名、修改私密备注或追加无关条目不使本轮失效。新轮用最新设置和当前发布稿。
- 词表撤回/删除、成员移除或词条归档等使已发题失去读取资格时，停止该未完成轮次，不删题凑完成。合法恢复后明确重开一轮，原失效轮保留、不计完成；当日仍最多一个有效完成事实。
- 归档任务阻止新轮并取消未完成轮次，既有完成历史保留。用户到期注销立即拒绝学习写入；待注销但未到期仍沿用现有账号资格，钱包暂停不等于学习被暂停。

## 6. 什么是可信完成记录

服务端持久化以下链条：

`本人任务 → 固定轮次/业务日 → 固定题目与允许答案/规则版本 → 首次有效作答及服务端判定 → 唯一完成事实`

完成事实至少包含 completion_id、user_id、task_id、run_id、task_revision、task_type、question_type、business_day（仅每日）、固定题量、作答数、答对数、服务端 completed_at 和规则版本。每道题还能追溯 entry/publication/pos/sense/definition/form ID、题面与答案快照；快照只在后端判题使用，读取有严格投影。

- 服务端在最后一题事务内从持久记录重新计算 answered_count、correct_count；满足固定题量后创建唯一 completion_id，最后一题和完成事实同时提交或同时回滚。
- 首答、轮次开始和完成都有数据库唯一约束。网络重试、换请求键、并发标签页不能多记题或多记完成。
- 客户端不提交权威 student_id、completed、正确率、题量、完成时间、业务日或奖励金额；预期版本/前驱 ID 只能作并发前提，不能定义完成事实。
- 可信表示“服务端可复核这次练习符合既定完成规则”，不表示证明真人操作、掌握知识或没有查答案。创建多个短任务、反复学习仍可产生学习事实，未来计奖必须另行约束，不能逐 completion 无上限发币。
- 本人可以查看任务/轮次统计和已答记录。来源失去权限后，历史仅保留本人统计，隐藏对应题面、原答案及用户答案，不能用历史快照绕过当前内容权限。
- 建议个人任务、作答和完成明细随用户物理注销级联删除；本批不永久保存学习内容。未来奖励审计由 COIN-12 单独保留最小结算事实，独立账本和已有注销签署不级联删除。

## 7. 可观察验收

| 场景                              | 必须得到的结果                                                                     |
| --------------------------------- | ---------------------------------------------------------------------------------- |
| 每日 N 题都答错                   | N 次有效首答后完成，答对数 0；不是拒绝完成                                         |
| 少一题/空白/伪造 completed        | 不生成完成事实，空白和非法请求不占首次作答                                         |
| 双标签页、响应丢失                | 同题首答一次、同轮完成一次；不同答案覆盖被拒绝，原键重放返回原判定                 |
| 03:59/04:00、截止时刻及锁等待跨界 | 旧轮不计入新业务日；超时未提交不补记，先前成功请求仍可核对                         |
| 普通更新/归档/撤回                | 普通发布不改本轮答案；失去资格停止题面与提交，不能靠快照继续完成                   |
| 长期恢复和再开                    | 未完成轮可跨日继续；只有明确新轮动作才生成下一轮，旧开始请求返回旧轮               |
| 学生设置与身份                    | 必须是真实学生资格/已绑账号/已设置等级；切号不串数据，切教师视角不偷偷使用 C2      |
| 注销与钱包                        | 逻辑到期拒绝提交；物理删除清理学习明细且不破坏账本/签署；本批 coins 计数与余额不变 |
