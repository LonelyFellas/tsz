# 字典音标接入现有发音编辑器

## 目标与范围

在后台 V3「词形与发音」的每条发音记录中，为「字典音标」接入现有 `@tsz/voice-editor`，支持标注、发音配置、试听与保存。适用于统一、英式、美式和各词性/词形的发音行。复用现有编辑器交互，不新增 IPA 键盘。

用户已确认要使用现有发音编辑器。实际发音字段保持当前文本输入；不扩展到旧 V2 页面，不导入内置词典。

## 交互

1. 输入字典音标后，使用字段旁的编辑入口打开编辑器；沿用现有空文本禁用规则。
2. 编辑器的正文是该行字典音标，提供连读、停顿、音色、语速和音频工具；按用户补充要求隐藏语法结构工具。完成后返回输入框。
3. 修改正文时沿用现有标注范围调整和撤销逻辑。
4. 试听使用当前编辑内容和配置；不继续只朗读词形拼写。
5. 音频上传沿用已有环境开关和资产服务；未配置时显示现有不可用说明。
6. 草稿保存、刷新、进入下一步、发布再读取，均不能丢失标注、配置或音频引用。

## 验收

- 老的纯字符串发音记录可正常打开、编辑和保存。
- 多行发音各自独立；编辑一行不影响另一行。
- 缺失音标和超过 200 码点的错误仍能定位到实际输入框。
- 标注和配置经真实后端保存后可恢复；无效标注范围、正文不一致被拒绝。
- 音频引用须按本词条有效资产校验；保存词义不得移除发音行的有效音频引用。
- 不以 Mock 音频证明真实 TTS 成功。本环境尚未配置 Azure TTS 或对象存储，真实试听/上传需按实际依赖记录结果。
