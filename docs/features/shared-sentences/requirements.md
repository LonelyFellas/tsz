# 独立多维例句

后台从“多维例句”进入独立列表：按 ID/正文/创建人、等级、创建时间查询，分页；展示关联具体词条、创建/更新时间及查看、编辑、删除。正文两行截断，关联最多两项。不提供新增、审核、发布或生成题目入口。

新增只能从已创建的具体词条编辑器发起；编辑器“完成”独立持久化例句，立即可见，无审核状态。取消外层词条不撤销完成的例句；关闭未完成例句编辑器不写入。一个例句 UUID 对应一份当前内容，多词条正式收录引用同一实体。

句内片段可关联具体词条，支持多个词/短语。未建词条保存片段、类型、待关联文字与上下文，不自动创建空词条。同拼写不自动绑定。当前词条自动收录；其他已标注词条和待关联文字匹配的词条获得候选，人工确认才收录；待关联确认同时绑定具体词条。

共享编辑需提示影响当前引用；删除需显示影响并使所有当前引用同时不可见。不要求兼容历史数据。并发修改返回冲突，创建重试不重复。

验收：例句完成→列表刷新→当前词条收录；其他具体词条候选确认；待关联同名歧义人工绑定；共享修改、删除和取消/重试；管理员权限；新结构迁移。完整本地验证后保留服务，无提交推送部署授权。
