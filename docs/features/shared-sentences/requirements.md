# 多维例句：关联到具体词义

2026-09-13。用户确认：句中的单词/短语关联到词条下的具体词义；新词义先保存，再添加例句。本轮在独立本地环境实施，保留此前页面与未保存输入。

## 核心模型

例句正文、译文、音频和句内标注仍独立保存在例句库。真正的引用是“句内片段 → 具体词条 → 词形 → 词义”，不能只保存词条 ID。

例如 `We make the story up.` 的 `make … up` 关联到 `make up → 原形 → 编造（故事、借口等）`，不会因此出现在“和好”的例句列表中。

- 每个词义卡片内展示“多维例句”，与多维释义等区块同级，排列在“多维释义”下方、“成分用词”上方。
- 列表按同一条真实 annotation 的 `target_entry_id + target_sense_id` 反查；一条句子在同一词义内只显示一次。词条汇总按句 ID 去重。
- 不建立独立收录清单，不复制例句正文到 meanings，不恢复以前的 sense collections/暂存提交方案。
- 同一句可以通过不同片段关联不同词义，所有入口编辑的是同一个句子实体。

## 创建与编辑

1. 当前词义已保存且仍属于当前词条，才开放“添加例句”；未保存的新词义提示“先保存词义，再添加例句”。不隐式保存整页词义。
2. 新增和编辑直接展示 voice-editor，保留文本、关联单词/短语、连读、停顿、发音、音频功能。
3. 至少一条完整、有效关联必须指向进入页面的当前词义；只有相同词条而词义不同不满足完成条件。
4. 已检测到对应片段时，自动确认入口绑定当前词义及明确的匹配词形；同一表面形式有多个有效词形候选时，由用户选择，不能猜选第一项。
5. 编辑器可打开以修复失效关联；保存前校验完整目标身份、正文位置、词形匹配与版本。选择器层级和多维释义复用，短语直接关联其自身的词义。
6. “完成”只保存例句，正常保存词义不回写例句。例句的共享影响提示包含关联词义数量。

## 句内关联规则

- 界面采用“词条 → 词形 → 词义”的选择链。词性作为必要的从属身份保存，存在歧义时展示词性名。
- 已有关联显示词条与词义摘要；允许清除和重新选择。其他片段的关联也必须选择到具体词义。
- 必须验证词条、词性、原形、词形变体、词义的从属关系及选择文字，不能伪造另一词条或另一词性的 sense ID。
- 当前词条允许成为目标：例句是独立实体，此处不适用词义正文的禁止自指规则。
- 词条尚未创建时可保留 Pending，文字取自片段且只读；Pending 不计入任何具体词义列表，也不能满足当前词义的必需关联。
- 原文改错再改回时，恢复此前完整的目标身份；手动清除/改选不自动恢复。保持上一轮的恢复边界及撤销/重做行为。

## 解除与引用保护

- 卡片操作命名为“从当前词义解除关联”，只移除这句所有指向当前 `entry+sense` 的标注。
- 保留例句、其他词义的标注，以及同一词条下其他词义的标注；因此一句可能解除后仍出现在该词条的另一词义下。
- 普通上下文编辑清除最后一个当前词义关联后不能完成；显式解除是单独的出口。全局编辑可将例句保存为无关联状态。
- 被共享例句引用的词义或目标身份节点不得悄悄删除/改组。删除前应解除或调整例句关联；不级联删除例句、不自动改绑其他词义。
- 管理员读取全局例句及引用候选不要求拥有被引用草稿；进入具体词义编辑仍遵守当前词条的写权限。

## 旧数据

现有 entry-only 标注保留为“待选择词义”，可从全局例句库进入修复。没有可靠词义证据时不猜配；不将它显示成已关联的某个词义。不清理既有数据，不沿用之前 29 条测试数据的清理授权。

已存在的 sense collections 历史表不作为新成员关系依据。新写入必须包含完整的词义目标；过渡结构保留旧行可读，防止未经确认的数据丢失。

## 保留的体验

仅新建例句时提供初/中/高/高译文模板；完成时过滤空模板，重新编辑只显示已保存译文，不自动补模板，至少一条译文；列表展示全部有效译文。保留精确原形/变形匹配、非连续短语、并发 revision、稳定创建 ID、未保存离开保护、逐字母贴合的连读弧线。

## 验收

- make up 两个词义：绑定“编造”的句子只出现于编造；同词条不同词义的 ID 不能混用。
- 相同句子不同片段分别绑定两个词义：两处显示同一 UUID；解除一处不影响另一处与句子正文。
- 未保存新词义不能创建；正常保存后入口开放；例句完成不触发词义保存。
- 新增/编辑直显 voice-editor；选择器可选择短语自身词义，并保留现有多维释义选择器原行为。
- 缺少 sense、伪造父子身份、Pending、失效词形/位置、版本冲突均不能越过写校验。
- 被引用词义删除及词形节点裁剪受保护；全局可修复旧 entry-only 关系；迁移回退不丢新目标数据。
- 契约、真实浏览器和持久化查询一致；旧本地环境继续可用。
