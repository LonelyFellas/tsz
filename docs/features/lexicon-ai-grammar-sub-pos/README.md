# 语法结构生成推荐细分词性

候选按句型推荐一个细分词性。Rust 从当前词条类型的词性目录读取基本词性及其细分项，向 Agent 提供编码和中英文名称。Agent 按句型实际用法选择编码。目录没有选项或证据不足时保留句型候选并省略推荐。

生成和候选回读均使用可选的 `sub_pos`。前端通过 `x-tsz-next-grammar-sub-pos: v1` 协商该字段，Rust 仅在 Agent 宣告支持时透传目录，并检查推荐编码属于候选的基本词性。目录内容纳入缓存绑定。旧前端或旧 Agent 继续使用仅含基本词性及句型的响应。

后台预览显示目录名称，一键配置将有效推荐填入对应新增或未分类的结构，保留已有细分词性和人工内容。使用独立环境生成 `rely` 的语法结构，核对 `rely on ...` 推荐当前目录下的不及物动词。保存并刷新后核对细分词性和句型。目录外编码与无推荐的响应由契约及回填测试覆盖。
