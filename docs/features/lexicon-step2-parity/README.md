# 新版智能词库 Step 2 对齐 V1

## 范围与验收

- 沿用 Step 1 已确定的目标语言，Step 2 不重复选择语言或通用英语内容。
- 复用 V1 `V3FormsAndPronunciationStep` 及其词形内容窗口、词性目录、英美拼写、词形变化、多读法、音标和配音配置；不另外建立一套编辑器。
- 新版词条继续使用独立身份与存储；保存后重新打开保留完整编辑内容，列表检索和词形预览反映已保存拼写。
- 保存等待发音处理；失败、版本冲突、只读和内容窗口的未保存离开保护继续生效。
- 不扩展 Step 3，也不增加发布、候选生成或跨词条关联能力。

## 实现与兼容

前端工作区：`codex/lexicon-step2-parity`；后端配套工作区同名分支，基于 `526cddc`。后端主记录引用本文件。

新版 `NextDraft` 增加可选、非 null 的 `form_editor`，直接使用现有 `SharedFormsStepContentV3` 契约与校验，不转换成旧版词条。原 `forms` 内容保留在已有词形折叠区，保存不自动迁移或删除。编辑器的拼写以内容 slot ID 投影到新版现有检索表；完整内容写入原有版本快照。

客户端以 `X-TSZ-Next-Forms: v1` 请求能力目录；仅协商后的响应携带 `form_editor: true`。新客户端遇到旧后端不开放此编辑器。含新编辑内容的草稿拒绝缺少该字段的旧保存请求，避免旧客户端静默覆盖。

后端迁移 `20261113120000` 新增独立的编辑节点身份和音频引用表。录音元数据以服务端为准，按资产锁防止并发跨词条占用及回收竞态；回收与读取权限同时识别新版引用。

## 发布和回退限制

本地实施与验证已完成。用户已授权两仓创建 PR、跟进 CI，通过后合并并配套部署到 tshb-test；当前进入提交与独立审查阶段。

配套上线需先完成后端迁移及服务更新，再上线前端。启用新草稿写入前应停止旧版本的音频回收进程；旧进程不识别新版音频引用，不能与新写入混用。已有 `form_editor` 快照期间不可回退到旧后端；down migration 会拒绝此回退，不能通过丢弃字段恢复兼容。
