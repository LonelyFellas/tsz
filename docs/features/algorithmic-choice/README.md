## 干扰项质量优化（本地实施）

本批目标是在既有按需出题中提高干扰项语义相关性，排除已知第二答案；不调用 AI，也不引入人工审核。前后端独立分支为 `codex/choice-distractor-quality`，后端基线 `867053dc`，前端基线 `0e81312a`。本批不改变 wire/API，不提交或部署已有业务数据。

依赖路径：当前发布词形 → 已导入 Kaikki 词典正文的可追溯派生证据 → 义项对应/语义召回 → 全义项风险检查 → 质量排序 → 固定学习快照。复用词库发布、基本词形/词性/等级/英美档位、去重、来源有效性和旧快照判分。新增派生表只为已发布学习词形提取信息，随正文导入/更新、词条发布/激活维护，不在请求中扫描整个外部词典。原始词典版本与来源定位保留在既有 import 和 entry_contents，运行时仅读取 active 数据集。

当前规则：用中文译词的完整释义片段对应当前词性下的离线义项；缺中文对应时仅接受该词性明确只有一个有效义项的词，无法对应的多义词不猜测。质量候选需有具体共同上位概念，或明确同类/反义关系，通用 entity/thing/person 等分类不作质量依据。先从该语义范围分页读取，再按结构关系强度、等级接近度和词长选择，禁止无关的近拼写词兜底。

风险排除覆盖候选和答案全部已知义项/词性：同义、词形/拼写变体、共同别名、上下位直接答案关系、中文完整译义重合、英文等价释义和明确“Synonym of …”式定义。候选的发布中文其他义项继续核查。中文不再按共同单字一票否决，否定词保留。缺离线证据、证据投影不完整/超限、义项无法对应或合格干扰项不足三个时不出题。

取舍：更严格的证据门槛会降低缺双语释义/结构关系词条的可出题覆盖。规则只排除词库和离线词典已表达的风险，不能宣称证明自然语言所有潜在含义；已经持久化的旧练习继续使用原快照，新算法只影响后续出题。

验收围绕相关候选优于无关近拼写、整义相同但无共同汉字的同义词、隐藏第二义项、上下位词/变体、缺证据/候选不足、跨页继续查找、派生索引更新与回退，以及 50k 候选/1000 目标性能。本地实施已完成，验证结果见下文。

## 按单词掌握情况安排练习（本地实现与验收）

依赖：现有任务/学习单元/固定题目与判分事实可复用；干扰项语义质量优化继续保留。新增 `mastery_v1` 模式承载持久化队列和每词义掌握状态，不把首次覆盖当作掌握，不重刷固定整轮。前后端当前已对齐 main：`857d513d` / `9841594`，继续复用本任务独立 worktree。
