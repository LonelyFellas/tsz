# 单选题改为规则生成

## 当前目标：学习任务按需出题

用户已明确取消工作台、全库预生成和人工审核。前一版只替换生成服务的实现已经交付，但不是最终产品形态；下文旧版记录仅为历史证据。

剩余关键路径：学习计划投影与选项算法 → 按需快照/来源有效性 → 移除 Admin/API/生成队列 → 契约同步 → 隔离真实联调。当前在 `codex/on-demand-choice` 前后端独立 worktree 实施，已对齐前端 `bb41f144`、后端 `a972662`。

- 复用：鉴权、发布快照、学习单元/轮次、能力协商、选项 ID 判分、恢复、奖励去重和拼写记忆隔离。
- 新工作：计划预览依当前词义、等级和档位计算可成题单元；计划仅冻结学习目标，首次开练在同一事务生成并保存当前批次选项。后续请求使用已保存快照，不重抽题。
- 算法：仅选有效发布的基本词形，同词性、允许等级和英美档位；去除同词条、有效拼写重复及所有已发布释义中的字面重叠，按词形相似程度选择。已知重叠采用保守排除，包括 take/bring 的“拿、带”；候选不足排除该单元，不调用模型或引入审核。规则只能根据词库与字面信息筛选，不等于对未收录语义的通用证明。
- 移除：题型管理菜单、单选工作台、词条命题入口、预生成/审核/Agent 回调端点与 worker。共享模型账号连接和用量账本继续复用 Agent 连接配置。
- 历史：旧题库记录保留为证据，迁移取消未完成预生成并停用旧题。已有完整学习快照继续按发布来源校验、恢复和判分。新任务不读写题库，也不因后台审核状态影响学习。
- 验收：空题库可创建/开始/答题；计划内尚无选项、开练后固定四个不透明 ID；刷新与幂等不重置；候选不足、释义重叠、来源撤回、旧快照、拼写/奖励隔离通过；工作台页面和写入口不可达。真实浏览器验证使用独立本地数据库、Redis 与测试账号，不创建 OSS 资产，结束后彻底清理。
- 发布边界：前端先移除旧入口，再升级后端；旧 Admin 对新 API 的题库请求为 404。C 端现有学习 wire 保持不变。新增按需快照后禁止直接回退旧后端；代码、真实联调、提交/PR、部署分阶段报告，当前请求终点已延伸到审查修复、提交、推送及前后端 PR。

## 前一版目标和范围（历史）

新单选题由后端从已发布词库按词性、等级、档位和拼写去重筛选候选，并按现有字面相似度排序选择三个干扰项；不调用 AI。生成只产生草稿，审核人员必须逐项核对语义和答案唯一性。候选不足明确失败。已有 AI 题目停用，不再允许审核启用；历史作答快照保留。

## 依赖与切换

复用现有候选索引、来源校验、题库审核和学习快照。迁移标记旧生成任务为 AI、取消未完成任务并停用旧题；新任务标记为算法。已有远端执行身份的旧任务仍需取消；远端身份未知时不得重放创建请求，须人工核查远端残留。算法生成的审核不再向 Agent 发送反馈。

旧后端不能与迁移后的数据库并行处理任务：旧 worker 不识别生成方式，可能将新任务发给 Agent。部署应先停止全部旧 worker，再迁移并启动新后端，验证旧执行停止及生成路径后更新前端。新题产生后 down migration 禁止直接回滚；旧题停用也不会由 down 自动恢复。发布前必须核实生产版本、在途任务及回退方案。

## 验收

- 未配置 Agent 时仍可生成草稿、审核、创建学习任务并答题；候选不足不生成题目。
- 已有 AI 题目不再用于新题和未完成学习批次，历史结果仍可读取；不能直接重新启用。
- 作答前不泄露答案；来源、权限或审核版本改变后沿现有校验处理。
- 代码测试、隔离数据库迁移和真实前后端链路分别记录；未验证项不得视为通过。
