## 回退

在任务分支上两个批次各有独立提交。只撤列表批次可以保留新框架；整个试点需要按列表、框架的顺序撤回。合并前可以继续使用原分支；合并后按实际合入提交创建 revert PR。基线标签用于核对差异，保留其后的其他主线改动。两个批次均无数据库或存储迁移。
