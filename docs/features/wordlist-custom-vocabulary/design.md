## 产品规则

1. 搜索成功且没有匹配时可录入自定义词，搜索失败不自动转为自定义。自定义词面必填、最多 50 字，释义必填、最多 200 字，注最多 1000 字。平台既有长词面不套用自定义长度限制。
2. 自定义项归属词表，不写平台词库；返回编辑保持来源，不因平台后来出现同名词而改绑。词面相同不等于相同词条，不自动合并内容。
3. 平台项与自定义项共用顺序和 10000 项上限。自定义项具有稳定 `item_id`，改词面、排序、分页后注和私密备注仍归属原项。
4. Excel 沿用三列表头和本地解析；未匹配行可明确选为自定义并填写释义，匹配的释义仍以平台为准。错误、取消和晚到请求不得丢失原编辑内容。
5. 标准/完整阅读、自有详情、后台当前内容和审核快照均识别自定义项；只展示真实词面、释义和注，不伪造词性、音标或平台链接。私密备注不出现在公共/后台响应。
6. 沿用当前人工公开审核、撤回后编辑和版本保护。审核记录保存当时的自定义文本和顺序，旧快照不能批准新版本。
