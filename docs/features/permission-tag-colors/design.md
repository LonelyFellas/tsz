# 权限标签颜色设计

依赖：后端 `permission_tags` 已有名称、版本与权限关系；前端已有标签管理抽屉和标签池。新增工作仅为标签颜色持久化、接口字段及各入口回显。

- 后端新增 `color` 列，默认 `default`；先允许 `default/blue/cyan/green/gold/orange/red/purple`，再由增量迁移允许 `#RRGGBB`。服务端把 HEX 统一存成大写。创建与 PATCH 请求的 `color` 可省略，兼容旧客户端；响应总是包含颜色。PATCH 继续使用 `expected_version`，颜色修改增加版本并记录审计。
- 前端 `PermissionTag` 镜像新字段；标签编辑弹窗提供预设色和不透明取色器。表格标签、管理抽屉和管理员授权标签池按字段显示；antd 将自定义标签底色调浅，因此统一使用深色文字。旧后端缺字段时退回中性色。
- 发布顺序：先迁移并发布后端，再发布前端。新后端兼容旧请求；新前端在旧响应缺颜色时可显示默认样式，但其带颜色的写请求会被旧后端拒绝，因此不能先发布前端。
- 回退限制：回退自定义色约束会把已保存的 HEX 颜色改为 `default`；删除 `color` 列会丢失所有颜色。前端回退不影响后端保留颜色数据。
- 验证：Rust 权限标签 handler 集成测试、OpenAPI 导出及前端契约测试、admin 标签交互测试；本地隔离数据库和浏览器手动复核。
