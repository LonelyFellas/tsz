# 统一密码规则

用户已批准新规则；不实现旧大小写转换方案。

- 所有新密码为 15–128 Unicode code point，允许符号、中文和空格，无字符组合要求。
- 密码原样输入、传输、验证，区分大小写，不 trim、不截断。
- 后端统一执行常见/泄露密码与账号关联弱密码检查，前端仅即时长度校验。
- 新密码使用 Argon2id 加随机盐；登录仅验证，不执行新密码策略。
- 注册、重置、改密和管理员临时密码/seed 都不能绕过策略。
- 注册/重置的密码错误不消费验证码。改密/重置撤销已有会话。
- 复用原有接口，新增稳定密码错误码；所有页面显示一致中文提示。
- 本地泄露数据集有固定来源、范围与更新说明；不向外部发送密码。
- 本任务只实现和验证，不提交、推送、部署；不清空已有账号数据。
