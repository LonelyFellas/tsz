# 后台 UI 体系收拢

## 目标与当前范围

在现有排版上统一后台视觉与交互细节，让后续 AI 有稳定的读取入口、共享实现、样板和偏差检查。品牌、导航、网格、控件承载方式与操作顺序保持原有结构；接口、权限、提交时机和持久化格式不变。

首轮建立共享基础和三个样板，本次继续覆盖剩余页面、深层编辑和浮层。全部后台 CSS 已接入共同变量体系与自动检查；口音、权限标签、图表和品牌插画等业务配色保留含义，不套同一种页面模板。

长期规则只维护在 [Admin 界面规范](../../../apps/admin/style.md)，本文记录评估、实施范围与验收。当前分支 `codex/admin-ui-system`，基线由 `b86aefde` 快进到 `aba9af8e`，直接纳入主线的账户长名称修复 #687。当前交付终点为审查、提交、推送并创建 PR；不包含合并与部署。

## 评估与处理

| 现状                                         | 影响                                        | 实施                                                                                |
| -------------------------------------------- | ------------------------------------------- | ----------------------------------------------------------------------------------- |
| 已有表单、表格、浮层、工具栏与列设置         | 能复用，不需要更换组件库                    | 继续使用 `@tsz/ui/admin/*` 和现有业务模型                                           |
| 品牌色、中性色、尺寸和焦点在各页面重复定义   | 同一角色的视觉容易漂移                      | `admin/tokens.css` 维护值，页面别名和 Tailwind 主题引用同一来源，JSX 桥接不另存色值 |
| 普通页面用面包屑承担标题，复杂页面各自写标题 | 层级和动作排列不稳定                        | 普通页面使用 `PageHeader`；首页、认证页、专业编辑器保留现有结构并共用字号尺度       |
| 状态表达分散，局部样式覆盖控件               | hover、focus、loading、error 的含义容易分离 | 统一共享状态，错误焦点保持错误语义，组合输入围绕整体显示焦点                        |
| 页面尺寸与间距重复，部分辅助文字偏淡         | 细节缺少统一来源                            | 使用共同尺寸、间距和文字语义，保留专业列宽、断点、词面字体与数据强调                |
| 新页面不在原检查名单中                       | 后续 AI 新增文件可能漏检                    | 自动扫描全部后台 CSS，新增样式自然进入检查；检查随既有 lint / CI 执行               |
| 编辑器助手盖住固定底栏                       | 主操作被遮挡                                | 按底栏实际位置和高度避让，响应窗口缩放与底栏换行，离开页面清理布局变量              |
| 宽内容的居中弹窗在窄屏仍按内容宽度撑开       | 关闭、保存等操作可能位于屏幕外              | 居中网格使用 `minmax(0, 1fr)`，弹窗允许收缩；例句说明和等级控件自然换行             |

## 长期约束

- 根 AGENTS 指向唯一界面规范；规范链接组件与样板，组件实现默认行为，变量文件维护设计值。
- `pnpm check:admin-ui` 自动扫描 `apps/admin/src` 和 `packages/ui/src/admin` 的全部 CSS，当前 39 个文件。唯一排除项是变量定义文件本身。
- 检查重复品牌色、共享变量覆写及无 fallback 的未定义设计变量。业务配色仍允许独立表达，不用忽略名单掩盖漂移。
- 检查接入 `@tsz/ui` lint；Turbo 将检查脚本及 admin CSS 纳入该任务的输入，避免缓存漏掉规则或页面变化。admin ESLint 禁止重新引入 AntD、MUI、Emotion。
- 自动检查不代替视觉判断。后续公共规则变化需同步核对规范、变量、受影响页面和截图。
