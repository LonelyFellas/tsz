# 后台 UI 体系

## 本轮范围

2026-11-14，本轮按用户要求只优化登录、工作台、个人设置，并收紧后续 AI 使用的视觉与交互规范。业务接口、权限、提交时机、草稿和持久化格式沿用现有实现。

长期规则维护在 [Admin 界面规范](../../../apps/admin/style.md)，设计值维护在 [tokens.css](../../../packages/ui/src/admin/tokens.css)。此前的基础收拢已在 PR #689 合入；其截图只代表历史版本，不作为本轮验收证据。

| 工作台动效 | 指标与周数据滚动、卡片淡入、柱状图和进度条生长、入口悬停反馈；减少动态效果时直接显示最终状态                |
| 共享样式   | 补充字号、字重、间距、圆角、阴影和动效变量；Info 提示框改用等值变量，大号按钮统一正文大小                   |

登录插画中保留四处排版偏差（三处字号、一处 `font` 简写），作为插画几何尺寸记录在基线；其他页面不在本次迁移范围。旧文件现有偏差不能增加，修复后通过 `pnpm check:admin-ui:tighten` 收紧，不增加忽略名单。

## 验收证据

本轮本地页面由该任务 worktree 的 Vite 服务提供，并通过代理连接真实测试 API。登录后查看工作台及设置分区；未以 fixture 替代这些页面请求，未修改模型、连接外部账号或创建业务测试数据。

- 登录表单在桌面与窄窗口检查；工作台及设置三个分区检查 1440 / 900 / 768px，未出现整页横向溢出。
- 浏览器抓帧确认指标数字变化并停在最终值，切换周次后周统计滚动到对应值。
- 数字可见文本参与动画，屏幕阅读器始终读取最终值；超出安全整数范围的金额直接显示原始格式化结果。
- 受影响 Admin 测试 22 个文件、177 个用例通过；共享 UI 43 个用例通过。
- 动效加入后，页面和 dashboard 回归 14 个文件、215 个用例通过；其中 CountUp 三项测试使用假计时器验证动画完成、减少动态效果和大整数。
- 样式检查及其九项测试、定向 ESLint、Admin 类型检查、变更文件格式检查通过；审查发现的字重与 `font` 简写漏检已补充失败复现并修复，两条新增规则的初始存量取自固定主线 `0427931f`；同步同期主线 `92cfe835` 时，仅补入该主线词库样式已有的一处字重，既有规则基线未调高。

独立审查连续发现同一规则漏检根因：只匹配特定字面量，没有先处理 CSS 声明的优先级与大小写。修复统一规范化声明值，并覆盖 `!important`、关键字、数值表示及 `font` 简写反例；后续仅复查该增量，不重做未变的页面审查。

以上为实施阶段证据。最终精确提交的独立审查、原生 hooks、PR / main CI、Admin 制品及部署验收结果记录在本轮 PR；不把本地页面验证当作服务器发布成功。
