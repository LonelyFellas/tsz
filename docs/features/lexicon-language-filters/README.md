# 智能词库语言筛选

目标：新版列表、词条/词义搜索、垃圾桶、分页和统计使用一致的目标语言与媒介语言口径。复用词条及多语言内容模型，不复制词条，不开放新的语言创编能力。

## 查询规则

- `target_language` 为词条归属语言（如 `en`），精确匹配；省略时跨目标语言查询。
- `medium_locale` 为媒介内容的具体语言变体（如 `zh-Hans` / `zh-Hant`）。选定时，词条必须有该语言的释义或译词；词义搜索与常见释义也只取该语言。没有释义但有译词时，常见释义展示译词。
- 两项默认「全部」，保留尚无内容的空草稿；选定媒介语言后空草稿不命中。语言选项来自 capabilities。筛选不构成权限边界，所有请求保留现有鉴权。
- 列表、垃圾桶、分页总数、统计共用后端过滤条件；统计复用当前已提交的业务条件，忽略分页。今日与本月沿用北京时间。
- 筛选提交时回到第 1 页并清除已选词条；分页、状态切换、刷新与前进后退保留语言条件。进入/返回垃圾桶保留语言条件。缓存键包含条件。
- 无语言参数的旧请求继续可用；新前端的语言参数需要配套后端先上线。响应结构不新增字段，旧前端可读新后端；回退后端前须先回退前端。
