# 智能词库 IPA / UPS 正式接入

用户最终确认只保留 IPA/UPS，SAPI 不再作为功能选项。实现与本地验收已授权，提交/推送/部署未授权。

- 固定链：字典音标 → 实际发音；实际发音 → Azure IPA/UPS，无来源下拉、不自动回退其他字段。
- 保留正式实际发音富文本编辑/连读标注；字典填入会确认清除原标注且可撤销。
- IPA/UPS 候选独立，覆盖需确认、支持撤销；转换不改当前来源。
- 来源可选词形拼写/IPA/UPS。切换来源不删除其他候选。
- 短语 UPS 连续显示，逐词边界单独保留，编辑后不猜测边界；失效时阻止不可靠试听/完成校验。
- 复用正式鉴权、语音目录、音色配置、录音接口和 speech/previews，不引入 harness 的密钥或直连 Azure API。
- 旧 UPS 内容、原始来源与旧 JSON 读取保真；新增字段可缺省，不能静默改名。
- UPS 自动转换仅已验证的 en-US 表，其他口音/未覆盖规则明确提示；不因用户主观听感擅自替换音素。
- 实验性 IPA 加点仍留在 harness，正式代码不默认增加音节点。

验收：共享转换与边界单测、正式组件固定来源与撤销、契约生成/验证、旧数据序列化、本地真实登录→编辑→保存→独立 GET/刷新→正式语音接口→音频。

用户反馈为“几乎没有差别，无法保证真的一样”，不是全部音色、全部规则的音值等价证明。
