补充：文档 1.1.2 节把 Alice blue 的色盘指向 `#EAF9FF`（浅版），与表格里的 `#BFC0CA` 并存。

难度级别标签的渐变序列（A1→C2，原文「左侧渐变色序列」）：
`#2053FF 75% → #2053FF 100% → #6C00FF 75% → #6C00FF 100% → #D22D8D 75% → #D22D8D 100%`
设计依据（原文）：最低级别与最高级别的颜色与主题色保持一致，同一大级别内区分深浅、色相一致。

## 2. 字体（原文 1.2 节）

| 用途             | 西文          | 中文                   |
| ---------------- | ------------- | ---------------------- |
| 正文             | Ubuntu        | 更纱黑体 Sarasa Gothic |
| 英语音标         | Inter         | —                      |
| 以数字为主的标签 | Source Sans 3 | 更纱黑体               |
| 以英文为主的标签 | Ubuntu        | 更纱黑体               |
| 中文标签         | —             | 更纱黑体               |

硬要求（原文）：Ubuntu、Inter、更纱黑体必须打开 `liga` 标准连字功能。
字重由设计师斟酌，主要页面定稿后统一调整。

## 3. 屏幕适配（原文 1.4 节）

主要适配安卓平板（华为、小米），16:10。推荐 2880×1800（2.8K）、常见 2560×1600（2.5K）。
iPad 暂不专门适配。
⚠️ 该条针对 C 端学员产品，平台后台（桌面 web）不在原文覆盖范围内。
