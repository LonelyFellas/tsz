# Admin 界面规范

适用于 `apps/admin` 与 `packages/ui/src/admin`。本文是后台视觉与交互的唯一规则来源：变量值在 [tokens.css](../../packages/ui/src/admin/tokens.css)，组件行为在 `@tsz/ui/admin/*`，本文只写规则。

规则分两级：

- **必须 / 禁止**：没有例外。带「自动」标记的由 `pnpm check:admin-ui` 拦截，其余在审查中逐条核对。
- **默认**：没有业务理由时照做；偏离时在代码旁用一行注释写明原因。

## 0. 动手前

1. 读完本文，打开第 3 节对应页面类型的样板文件，按样板的结构写。
2. 先找共享组件（第 2 节）。只有共享组件确实不覆盖时，才在页面里写样式；样式值只能来自设计变量。
3. 只改任务涉及的页面。未改动的老页面不顺手迁移，但改到哪里，哪里就按本文收齐。
4. 通用设计技能、外部审美建议与本文冲突时，以本文为准。不引入新的配色、字体、组件库或营销式排版。

## 1. 硬性规则

| 编号 | 规则                                                                                                                                                    | 检查 |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| R1   | 颜色必须用 `--ui-color-*`。业务色（口音、图表、插画）先在组件根选择器声明为带语义的局部自定义属性，如 `--login-paper: #f9f5e9`，再引用。                | 自动 |
| R2   | 字号必须用 `--ui-font-size-*`，字重用 `--ui-font-weight-*`。                                                                                            | 自动 |
| R3   | 圆角必须用 `--ui-border-radius-*`；`0` 和 `50%` 除外。                                                                                                  | 自动 |
| R4   | 阴影必须用 `--ui-shadow-*`。                                                                                                                            | 自动 |
| R5   | 行内 `style` 只放运行时计算值（进度宽度、拖动位置、动态列数）。颜色、字号、间距、圆角写进样式文件。                                                     | 自动 |
| R6   | 禁止在页面中定义 `--ui-*` 变量，禁止重写品牌色值；变量只在 `tokens.css` 定义。                                                                          | 自动 |
| R7   | 页面标题必须用 `PageHeader`（唯一的 `h1`）。登录、改密、404 等整屏页面除外。                                                                            | 审查 |
| R8   | 内容分区必须用 `Card`；需要标题时放在 `title`，右侧链接或次要操作放在 `extra`。禁止用细线加留白自行拼分区。                                             | 审查 |
| R9   | 按钮必须用共享 `Button`。路由跳转的按钮外观用 `<Link className="ui-btn ui-btn-primary">`。禁止裸 `<button>` 加自定义样式模拟按钮；切换类控件见第 2 节。 | 审查 |
| R10  | 每个页面最多一个主按钮（`type="primary"`），放在 `PageHeader` 的 `actions` 最右侧。                                                                     | 审查 |
| R11  | 状态标签必须用 `Tag` 的语义色，映射见第 4 节；同一状态在全后台只用一种颜色。                                                                            | 审查 |
| R12  | 加载、空、错误是三种不同状态，必须分别表达（第 4 节）。请求失败禁止显示成「暂无数据」。                                                                 | 审查 |
| R13  | 禁止装饰性元素：分区标题前的图标方块、无信息量的插图、渐变、半透明毛玻璃。图标只在帮助识别时使用（入口列表、状态、只含图标的按钮）。                    | 审查 |
| R14  | 文案遵循根 AGENTS「去除 AI slop」：不写副标题式说明、操作提示、欢迎语。删掉后不影响理解的句子一律删掉。                                                 | 审查 |
| R15  | 只含图标的操作必须有可访问名称；键盘焦点必须可见；Tab 顺序跟随阅读顺序。                                                                                | 审查 |
| R16  | 样式改动不得改变业务行为：提交时机、接口、权限、分页（1 基）、持久化格式、弹窗退出规则保持原样。                                                        | 审查 |

## 2. 设计变量与组件

### 2.1 变量

页面只引用变量，不抄数值。下表列出角色；具体值以 `tokens.css` 为准。

| 类别     | 变量                                                                                                         | 用途                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| 品牌     | `--ui-color-primary` / `-hover` / `-active` / `-bg` / `-border`                                              | 主操作、当前选中、链接、焦点。禁止用于大面积背景                                       |
| 文字     | `--ui-color-text`、`--ui-color-text-secondary`、`--ui-color-text-disabled`                                   | 正文与数据；标签与说明；禁用                                                           |
| 背景     | `--ui-color-bg-layout`、`--ui-color-bg-container`、`--ui-color-fill-alter`、`-fill-secondary`                | 工作区底色；卡片与浮层；表头与轻分区；悬停与分段控件底                                 |
| 边框     | `--ui-color-border`、`--ui-color-border-secondary`                                                           | 可交互控件边框；卡片与分隔线                                                           |
| 语义     | `--ui-color-{success,warning,error,info}` 及 `-bg` / `-border`                                               | 状态，必须同时有文字或图标                                                             |
| 品牌整屏 | `--ui-color-brand-deep`、`--ui-color-brand-deep-text`                                                        | 仅登录等品牌整屏页                                                                     |
| 字号     | `display` 28 · `title` 24 · `heading` 20 · `subheading` 18 · `section` 16 · 正文 14 · `compact` 13 · `sm` 12 | 指标数字 · 页面标题 · — · 列表计数 · 卡片标题 · 正文与控件 · 次要链接与说明 · 辅助信息 |
| 字重     | `regular` 400 · `medium` 500 · `semibold` 600 · `bold` 650                                                   | 正文 · 字段标签与列表主文字 · 卡片标题 · 页面标题与指标数字                            |
| 行高     | `--ui-line-height` 1.57、`--ui-line-height-tight` 1.25                                                       | 正文；大号数字与标题                                                                   |
| 间距     | `--ui-space-1/2/3/4/5/6/8/10` = 4/8/12/16/20/24/32/40                                                        | 控件内 4–8；相关元素 8–12；卡片内边距 20–24；卡片之间 16；页面区块之间 24              |
| 控件高   | `--ui-control-height-sm/默认/comfortable/lg` = 24/32/36/40                                                   | 行内操作 / 默认 / 词库搜索 / 登录等宽松表单                                            |
| 圆角     | `--ui-border-radius-sm/默认/lg/xl/full` = 4/7/12/16/999                                                      | 标签与小块 / 控件 / 卡片 / 整屏表单卡片 / 胶囊与进度条                                 |
| 阴影     | `--ui-shadow-xs` / `-sm` / `-overlay`                                                                        | 分段控件选中项 / 悬浮提升 / 浮层与整屏表单卡片。普通卡片无阴影                         |
| 动效     | `--ui-motion-duration` / `-easing`；`--ui-motion-duration-enter` / `--ui-motion-easing-enter`                | 交互过渡；概览页入场与数字变化（见 5.6）。减少动态效果时自动归零                       |

词条拼写、词形、语法结构用 `--tsz-font-words`（Andika）；所有音标（输入、编辑、预览、列表、下拉选项）用 `.tsz-phonetics` / `--tsz-font-phonetics`。混排时只标记音标部分，中文标签保留界面字体。

数字统一 `font-variant-numeric: tabular-nums`。

### 2.2 组件选用

| 场景                     | 必须使用                                                              | 禁止                                     |
| ------------------------ | --------------------------------------------------------------------- | ---------------------------------------- |
| 页面标题、日期、页级操作 | `PageHeader`（`title` / `actions` / `children` 作元信息）             | 自写 `h1`、`Typography.Title` 当页面标题 |
| 内容分区                 | `Card`（`title` 内放 `h2`，`extra` 放链接或计数）                     | 自写带边框的 `div` / `section`           |
| 列表                     | `AdminTable`（含列设置、工具栏、窄屏处理）                            | 裸 `Table` 加自定义工具栏                |
| 筛选                     | 放在独立 `Card`，提交式搜索沿用既有时机                               | 改成逐键请求                             |
| 普通表单                 | `@tsz/ui/admin/forms` 的 `Form` 与控件                                | 原生 `input` / `select`                  |
| 连体控件                 | `Space.Compact`（输入 + 按钮、播放 + 输入）                           | 绝对定位把按钮叠进输入框                 |
| 视图切换（2–4 项）       | `Segmented`；需要开关语义（`aria-pressed`）时用分段按钮样式           | 各页自写胶囊                             |
| 页内分栏                 | 共享 `Tabs`，不覆盖其外观                                             | 自写胶囊标签栏                           |
| 状态                     | `Tag`（语义色）或 `Badge status`（行内圆点）                          | 自写彩色 `span`                          |
| 简短独立编辑             | `Modal`                                                               | —                                        |
| 保留列表上下文的详情     | `Drawer`                                                              | —                                        |
| 长流程、多步骤、复杂草稿 | 独立页面                                                              | 塞进弹窗                                 |
| 破坏性确认               | `Modal.confirm` / `Popconfirm`，按钮写明动作（「删除词表」）          | 「确定」「OK」                           |
| 空状态                   | 表格内 `TableEmptyState`；其他位置 `Empty` + `PRESENTED_IMAGE_SIMPLE` | 默认大插图                               |
| 首次加载                 | 卡片内 `Skeleton`；刷新时保留旧内容并在按钮上显示 loading             | 整页 `Spin`、刷新时清空内容              |
| 请求失败                 | `Alert type="error"`，附「重试」按钮                                  | 只弹 toast、显示为空数据                 |
| 无权限                   | `Result status="403"` 或 `BusinessPermissionGuard`                    | 静默隐藏整页                             |

## 3. 页面模板

所有工具页的骨架相同：工作区灰底（`--ui-color-bg-layout`），内容由 `PageHeader` 和若干 `Card` 组成，区块间距 24，卡片间距 16。整屏页不套这个骨架。

| 类型     | 结构                                                                                                      | 样板                                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 概览     | `PageHeader`（元信息放日期，操作放刷新 + 主按钮）→ 指标卡行 → 主列与 340px 侧栏的 `Card`；可用 5.6 的动效 | [Home](src/pages/Home.tsx)、[home.css](src/pages/home.css)                                                          |
| 设置     | `PageHeader` → 共享 `Tabs`（仅多分区时）→ `Card` 分区，内容最大宽度 880px → 设置项行                      | [ProfileSettings](src/pages/ProfileSettings.tsx)、[profile-settings.css](src/pages/profile-settings.css)            |
| 列表     | `PageHeader` → 筛选 `Card` → `AdminTable`（工具栏左：视图与批量；右：列设置）→ 分页                       | [UserManagement](src/features/users/UserManagement.tsx)、[AdminManagement](src/features/admins/AdminManagement.tsx) |
| 复杂列表 | 在列表基础上保留状态切换、展开筛选、统计、选中与批量操作                                                  | [SmartDictionary](src/features/dictionary/SmartDictionary.tsx)                                                      |
| 多步编辑 | 保留步骤、侧栏、正文与窄屏完成情况抽屉；不改成普通表单                                                    | [WordCreationLayout](src/features/dictionary/word-creation/WordCreationLayout.tsx)                                  |
| 整屏认证 | 品牌深色底 + 实底白色表单卡片（`xl` 圆角、`overlay` 阴影）+ 共享 `lg` 控件                                | [AdminLoginForm](src/features/auth/AdminLoginForm.tsx)、[admin-login.css](src/features/auth/admin-login.css)        |

### 3.1 页头

- 标题说明页面用途，不加副标题。面包屑只表示上层位置，不重复当前标题。
- `actions` 从左到右：元信息（更新时间）→ 次要按钮 → 主按钮。
- 页面有日期范围、生成时间等上下文时放在 `children`，用辅助字号。

### 3.2 卡片

- 卡片标题 16 / 600，用 `h2`，同时设置 `aria-labelledby`。卡片头 `extra` 放「管理词库 →」这类链接（`compact` 字号、品牌色）或计数（次要色）。
- 卡片内容的内边距由 `Card` 提供，页面只在模板需要时统一调整，例如设置页为 24。
- 指标卡：标签（`compact`、次要色）→ 数字（`display`、`bold`）+ 单位（`sm`）→ 变化量（`sm`，数值加粗）。不加图标和趋势装饰。

### 3.3 设置项行

左侧放名称（14 / 500），需要时在下方加一行说明；右侧放控件。行最小高度 40，上下内边距 16，行与行之间用 `--ui-color-border-secondary` 细线分隔。下拉框宽 220px。

### 3.4 入口与待办列表

图标块（32px，品牌浅底 + 品牌色图标）→ 主文字（14 / 500）+ 说明（12，单行省略）→ 计数（18 / 600）→ 箭头。整行可点击，悬停用 `fill-alter` 底色，箭头变品牌色。

## 4. 状态

### 4.1 状态色映射

| 语义                         | `Tag color`  | 示例                   |
| ---------------------------- | ------------ | ---------------------- |
| 待处理、待审核、草稿待提交   | `warning`    | 待审核、待核验         |
| 进行中、处理中、生成中       | `processing` | 审核中、生成中         |
| 成功、已通过、已启用         | `success`    | 已通过、已认证、已发布 |
| 失败、已拒绝、异常           | `error`      | 已拒绝、生成失败       |
| 中性、已禁用、已撤销、未设置 | `default`    | 已禁用、已撤销、未认证 |

角色、口音、词性等分类标签不是状态，可以使用业务色，但同一分类在全后台保持同一颜色。老页面中不符合此表的状态色，改到该页面时一并收齐。

### 4.2 加载、空、错误

- **首次加载**：在内容将出现的卡片内显示 `Skeleton`，保留页头。
- **刷新**：保留已有内容，在触发按钮上显示 loading。
- **空**：区分「还没有数据」和「筛选无结果」。前者按权限提供新建入口，后者提供清除筛选。
- **错误**：用 `Alert type="error"` 写明失败原因和恢复方式，附「重试」按钮；重试不得丢失用户输入。

## 5. 交互细则

### 5.1 按钮与操作

- 尺寸只改变高度，不改变字号。紧凑（24）用于表格行内操作；页面级操作用默认（32）；整屏表单用 `lg`（40）。
- 默认底部操作顺序为「取消」「主操作」，主操作在右。破坏性动作用 `danger`，按钮文案写明动作，确认文案说明实际影响。
- 提交中保持按钮宽度和文字，显示 loading 并阻止重复提交；失败时保留输入、选中项和当前步骤。
- 表格行内操作统一用 `type="link" size="small"`，破坏性操作加 `danger`，最多显示 3 个，其余收进「更多」。

### 5.2 弹窗与抽屉

- 新增弹窗与抽屉宽度从尺度中选择：`480` / `640` / `800` / `960`，窄屏统一用 `min(<宽度>, calc(100vw - 32px))`。老页面的宽度改到时再收齐。
- 取消、遮罩、Esc、关闭按钮、未保存内容和请求中的退出规则以业务状态为准，修改时核对所有退出入口。
- 抽屉的操作放在 `footer`；只读详情可以没有操作。
- 隐藏面板用 `hidden` / `aria-hidden` / `inert`；浮层保持既有的焦点管理和焦点返回。

### 5.3 表单

- 字段标签放在控件附近，错误放在字段旁，错误时聚焦真实输入控件。
- 禁用和只读要能区分开；禁用原因影响操作时要提供可访问说明。
- 日期范围只在完整有效或明确清空时提交。
- 英美内容合并复用原编辑面板，两侧各提供「采用此侧」，标明选中侧并要求显式确认；确认前保留原值，取消不覆盖内容。如果合并会舍弃正文、标记、配音或关联，不得默认取某一侧。

### 5.4 控件细则（共享实现已处理，页面不要覆盖）

- `Select`：下拉最小宽度 128px，受视口宽度约束；选项单行省略并保留悬浮全文；只读触发区为手形光标，可搜索输入为文本光标。
- `Space.Compact`：统一外侧圆角、单线接缝与焦点层级。自定义输入包装层标记 `data-ui-compact-item`；`size` 统一组内控件尺寸。
- 搜索：输入即过滤用带图标的 `Input type="search"`；提交式用 `Input.Search` 加 `onSearch`。启用 `allowClear` 后只保留一个清除入口。
- `Radio`：按钮式 Radio 整个外框可点击，方向键切换时跳过禁用项；业务色只作用于实际圆环。
- `Tabs`：选中状态与键盘焦点分开表达，焦点框只在键盘导航时显示。
- `Card` 标题栏垂直居中；业务增加最小高度时沿用共享规则。

### 5.5 专用布局

- 配音中心使用 1200px 定宽工作区，词条内配音音色池使用 1120px 定宽，窄窗口通过外层横向滚动访问。
- 专业编辑网格、列宽、文本测量、拖动手柄按业务需要设定，不强制使用间距刻度。

### 5.6 动效

动效只用来说明「数据到了」「数据变了」「这里可以点」，不做装饰。

- **概览页（工作台类）允许**：
  - 卡片按阅读顺序依次淡入上移 8px，单个时长取 `--ui-motion-duration-enter`，整体错开不超过 300ms。
  - 指标数字用 [CountUp](src/features/dashboard/CountUp.tsx) 滚动（首次从 0，刷新或切换时从旧值）。
  - 进度条从左生长；图表首次渲染时生长。
  - 入口行悬停时图标块变为品牌实底，箭头右移 3px。
- **列表、表单、编辑、设置页禁止**入场动画和数字滚动，只保留 hover、focus、展开收起等交互过渡（`--ui-motion-duration`）。
- **必须**：
  - 时长、缓动只引用设计变量，减少动态效果偏好下直接显示最终状态。
  - 数字滚动只作用于可见文本，屏幕阅读器读到的始终是最终值。
  - 不能精确转成 `Number` 的值（如十进制金额字符串）不做滚动。
- **禁止**：循环动画、视差、弹跳，以及会让可点击元素位移的悬停效果；不得因为动画延迟操作或遮挡内容。

## 6. 响应式与文案

- 以 1440px 桌面和较窄的桌面窗口为准检查。窄屏时依次处理：工具栏换行、筛选纵向排列、侧栏落到主列下方、表格在内部横向滚动。禁止靠缩小字号塞下桌面布局。
- 中文、英文和较长的翻译都不能遮挡操作。使用已有 i18n 模块；文案 key 删除时一并删除未使用的翻译。
- 标题说用途，按钮说动作。只保留影响理解、决策、输入或纠错的说明。

## 7. 自动检查与基线

`pnpm check:admin-ui` 扫描 `apps/admin/src` 和 `packages/ui/src/admin` 下的全部 CSS 与 TSX（测试文件和 `tokens.css` 除外），随 `@tsz/ui` 的 lint 在 CI 中执行。

- **硬性错误**（任何文件都不允许）：R6，以及引用未定义的 `--ui-*` 变量。
- **偏差计数**（R1–R5）：`raw-color`、`raw-font-size`、`raw-font-weight`、`raw-font-shorthand`、`raw-radius`、`raw-shadow`、`inline-visual-style`。`font` 简写中的字号和字重同样检查，不能通过更换 CSS 写法绕过。
  - 存量记录在 [admin-ui-baseline.json](../../scripts/admin-ui-baseline.json)，**只降不升**：新文件必须为 0，老文件不得超过基线。
  - 新增检查规则首次接入时，只按固定 `origin/main` 提交中的存量建立该规则的初始计数，再按本轮修复结果收紧；既有规则计数不得调高。
  - 修复后运行 `pnpm check:admin-ui:tighten` 下调基线；存在超标时该命令拒绝写入。
  - 禁止手工调高基线，禁止为通过检查把字面量换成同值的无语义变量。确属业务配色时，按 R1 声明带语义的局部自定义属性。
- 自动检查不能证明视觉正确，页面改动仍需在浏览器中验收。
